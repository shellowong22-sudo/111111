# 根终端重启后受控预览验证

开发服务在本地端口短暂不可连接后已重启，并以 `curl http://127.0.0.1:3000/` 返回成功确认恢复。

受控预览首帧曾显示“数据库快照不可用 / 正在读取已导入数据库快照”，该状态在等待六秒后自动收敛：顶部显示“数据库快照”，右侧台账显示“已导入记录”，并列出 Apple、Microsoft、Alphabet、Amazon、Tesla、NVIDIA 与 Meta 等项目数据库导入快照、价格、变化及导入时间。

因此首帧提示属于异步查询加载瞬态，不作为数据库缺失或接口故障结论。该结果不改变默认行情仅读取项目数据库快照的既有边界。

在终端事实边界回归改为断言“项目数据库导入快照”后，受控预览再次验证：等待加载完成后顶部显示“数据库快照”，右侧显示“已导入记录”，并继续列出 Apple、Microsoft、Alphabet、Amazon、Tesla、NVIDIA 与 Meta 等项目快照。该文本校正未影响实际数据读取与渲染。
