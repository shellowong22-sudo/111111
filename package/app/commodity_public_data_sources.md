# 大宗商品终端内公开数据来源记录

**核验日期：2026-08-21。** 新增研究层优先直接读取 FRED 的公开 CSV 历史序列，以保障已有服务端读取模式、终端内渲染和透明来源边界的一致性。FRED 的商品分类展示了多个日频、周频、月频和年频序列；美国能源信息署说明其能源数据提供免费开放的 API 和批量下载；国际货币基金组织的基础商品价格数据库按月更新。[1] [2] [3]

| 数据层级 | 本次用途 | 终端处理 | 不适用范围 |
| --- | --- | --- | --- |
| FRED | WTI、Brent、Henry Hub 天然气、黄金与商品综合指数的实际历史观察 | 直接读取 CSV，显示最近可读观测、历史图表、共同日期比较和读取状态。 | 不作为交易所官方实时行情、可执行报价、完整期货曲线或逐笔成交。 |
| EIA | 未来可扩展的美国能源公开时间序列 | 本期不接入需登记密钥的端点；在资料说明中标注其公开 API 可用性。 | 不把未接入的库存、炼厂、产量或曲线字段填为示例值。 |
| IMF | 月度原材料价格长期比较的后续扩展参考 | 本期不混入日频 FRED 图表，避免频率和口径混用。 | 不将月度原材料指数描绘为日内或实时价格。 |

> 没有免费、可再分发且可稳定机读的完整合约期限曲线、交易所订单簿、持仓明细、可执行报价和资讯流。本期相关原入口保持真实空状态或明确资料边界，而不使用第三方网页跳转、抓取样例或合成数据。
