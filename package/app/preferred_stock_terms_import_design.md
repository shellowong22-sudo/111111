# 优先股条款批量导入与趋势筛选设计

本轮功能只在 **PSCH、EDS、WB、VIZ、CRD** 的既有终端内研究层中追加工作台、图表和筛选器，不改动任何原有优先股菜单、面板、字段或交互。导入文件仅在浏览器内解析为结构化行并提交规范化字段；原始 CSV 文件不存入数据库，也不会作为第三方网页阅读路径。

## CSV 条款字段标准

| 字段 | CSV 列名 | 类型 | 规则 | 覆盖状态 |
| --- | --- | --- | --- | --- |
| 证券标识 | `security_identifier` | 文本 | 必填；去除首尾空格；建议使用发行人代码/系列号/ISIN 的稳定识别符 | 核心必填 |
| 发行主体 | `issuer_name` | 文本 | 必填 | 核心必填 |
| 证券名称 | `security_name` | 文本 | 必填 | 核心必填 |
| CIK | `cik` | 数字文本 | 可选；1–10 位数字，规范化为 10 位 | 可选识别 |
| 分配类型 | `dividend_type` | 枚举 | `fixed`、`floating`、`fixed_to_float`、`other` | 核心必填 |
| 固定分配率 | `coupon_rate_pct` | 百分比数值 | 固定和固定转浮动类型必填；0–100 | 条件必填 |
| 支付频率 | `payment_frequency` | 枚举 | `monthly`、`quarterly`、`semiannual`、`annual`、`other` | 核心必填 |
| 参考指数 | `reference_index` | 文本 | 浮动和固定转浮动类型必填 | 条件必填 |
| 加点 | `spread_bps` | 数值 | 浮动和固定转浮动类型必填；-10,000–10,000 bps | 条件必填 |
| 重设频率 | `reset_frequency` | 枚举 | 浮动和固定转浮动类型必填 | 条件必填 |
| 首次赎回日 | `first_call_date` | `YYYY-MM-DD` | 可选；若给出必须为有效日期 | 推荐 |
| 到期日 | `maturity_date` | `YYYY-MM-DD` | 可选；若给出必须为有效日期 | 推荐 |
| 清算优先额 | `liquidation_preference` | 正数 | 可选；大于 0 | 推荐 |
| 来源标识 | `source_reference` | 文本 | 可选；应为可追溯的文件名、SEC 申报号或内部来源标识，不显示为离站跳转 | 推荐 |
| 截至日期 | `as_of_date` | `YYYY-MM-DD` | 必填；为条款记录的资料时点，不可代替实时市场时点 | 核心必填 |

## 校验、去重与导入边界

导入前按行返回 **错误、警告、可导入** 三类状态。错误行不会写入数据库；警告行可以导入，但会在覆盖报告中单独计数。服务器以 `账户 + security_identifier` 作为当前条款记录的幂等键：同一标识的后续成功导入更新该账户的当前条款快照，并把导入批次、时点和覆盖汇总写入审计记录。不会从 CSV 推断市场价格、到期收益率、评级、成交、库存或投资结论。

## 字段覆盖完整性报告

导入完成后自动对当批 **成功写入的条款行** 和账户级当前条款库计算以下报告：总行数、已导入行、拒绝行、更新行、警告行、核心字段覆盖率、条件字段覆盖率、推荐字段覆盖率、按分配类型的完整性、逐字段缺失数及需补证证券列表。覆盖率仅描述提供字段的完整度，不代表条款真实性、法律效力、市场流动性或可交易性。

## SEC 与 FRED 趋势多维筛选

SEC 趋势面板按 CIK、申报日期区间、表单、事件类别和文本关键词筛选实际读取的申报目录；图表按月显示申报次数，并显示筛选后的文件表。FRED 趋势面板按日期窗口、自定义开始/结束日期、利率/信用类别、具体序列和可读状态筛选服务器已返回的历史观察；图表只绘制保留的真实观测点。两类面板均不推断因果、价格反应或投资结论。
