# 地方债官方数据源审计

## 可直接在终端内读取

- **美国财政部 Fiscal Data — SLGS 日利率表**：官方数据集自 1992-06-15 起覆盖每日发布的 State and Local Government Series 利率，包含活期存款日年化有效利率与期限存款证券（1 个月至 40 年）利率字段。可通过 Fiscal Data API 在终端内读取，并在不可读取时显示真实空状态。
- **美国财政部 Fiscal Data — SLGS 项目统计**：官方月度项目统计可用于追加发行余额与到期结构研究，不替换 SLGS 原面板。

财政部的月度 SLGS 项目统计覆盖 2014-03-31 至 2026-07-31，按月发布，公开字段包括记录日、证券类型、证券类型说明、未偿证券数量和未偿本金金额。时间存款证券范围包括 Notes、Certificates of Indebtedness、Bonds 与 90 Day C of I，期限可从 15 天至 40 年；活期存款为一日 C of I。终端仅以这些原始官方字段呈现规模与结构，不把 SLGS 当成可交易市政债报价。

## 终端内数据边界

- **MSRB / EMMA 交易数据**：MSRB 说明地方债交易由交易商依 Rule G-14 上报，并在 EMMA 向公众展示；公开逐笔查询及订阅有访问边界，当前自动化读取受验证码限制。因此不能把受限逐笔交易数据伪装为开放 API 数据。
- 可在终端内保留 MSRB 数据口径、更新时间和真实空状态；如未来获得已授权的结构化访问，再仅在授权范围内填充实际成交字段。
- **FRED 市政债历史序列**：可作为高评级市政债长期历史参照，但已停止更新的序列不会被呈现为当前市政债曲线或实时基准。

## 设计原则

- 菜单、顺序、原字段、原图表和原交互不可替换或删除。
- 核心研究优先使用终端内的结构化数据、历史序列、比较和可视化；外部网站最多作为可选的原始证据核验入口。
- 不生成模拟成交、虚构发行、预测性结论或未获授权的评级迁移数据。

## 原面板阅读路径复核

对 21 个地方债原面板的代码审计显示，未发现以外部 HTTP 链接或窗口跳转承担主要阅读路径的实现。唯一包含 `https://` 的 MSRC 面板为 SVG 命名空间，不是用户可点击的网址。新增研究层不渲染外部链接，而是在终端中呈现官方读取结果、来源范围、许可状态、筛选、比较和真实空状态；原始网址仅保留在服务端来源元数据中，供后续受控核验使用。
