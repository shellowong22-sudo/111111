# Finance Hub Recovery 交付说明

本项目以用户上传的 `finance-hub-recovery-complete-archive-2026-08-26.zip` 为不可改写的业务基准。原始 ZIP 仅以只读来源材料保存；可运行项目位于独立工作副本。除经审计确认的最小运行修复和隔离式扩展外，冻结页面、终端框架、左侧导航、菜单层级、入口位置、路由和接口契约未被用未知版本替换。

## 本次已交付内容

全球股票目录已在不覆盖冻结 SQL 来源字段的条件下完成恢复：保留 5,088 条冻结 SQL 目录，仅新增导入用户提供 46 份 XLSX 中经内容去重和映射审计后的 43,668 条，当前 `equity_listings` 共 48,756 条、覆盖 40 个国家/地区。逐文件 SHA-256、工作表、列映射、有效/拒绝行、去重和冲突结论位于 `audit/artifacts-uploaded-global-equity-per-file-audit.json`，完整说明位于 `audit/15-global-equity-source-coverage.md`。

外汇入口位置保持不变，并追加了七个业务区分的终端内工作区：FXDS 公开序列契约检索、FXTF 代码规范词典、ALLQ 交叉转换参考、FRD 用户输入远期实验室、XDSH 布局管理、ECMI 相邻观察变化归档和 WCRS 窗口排名。冻结外汇面板保持可见；其中没有公开来源与观测时间的固定数值和详情已在保留内容边界中标为**模拟数据**。独立扩展不声称提供实时可执行报价、订单簿、官方 fixing、交易权限或预测。设计与验收记录见 `audit/17-forex-subfunction-audit.md`。
