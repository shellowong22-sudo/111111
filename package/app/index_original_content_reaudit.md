# 指数模块原内容零改动完整性复核

## 复核范围与结论

本轮复核以 `index_original_content_audit.md` 的保护基线为准，对 `IndexHub.tsx`、23 个原窗口面板以及两份原 CIX 聚合面板进行了逐项 SHA-256 重算。27 个受保护文件均与基线完全一致，未发现任何原内容改写、字段改名、顺序变化、原窗口替换或原交互删除。

原始 `PANEL_MAP` 顺序仍为：SECF、HELP_INDX、WEI、WEIF、WBIX、GMM、IN、INP、CIX、CIXB、AGG、FDFD、OTHER_INDEX、RRG、WT、CIXN、CIXS、CIXR、CIXC、CIXX、CIXI、INDEX_DERIV、BBG。原路由壳指纹亦与基线完全一致。

## 追加边界

`IndexPreservedModule` 先完整渲染 `children`，即原指数工作区；之后才追加独立的公开研究层、事件归档、账户篮子协作和官方权重导入工作台。追加组件均位于未受保护的新文件中，未向原面板写入字段、按钮、排序或数据替代逻辑。

## 数据、权限与终端内路径

| 审计项 | 复核结论 |
| --- | --- |
| 公开指数参考资料 | 仅读取 FRED 可读历史；不可读时显示真实空状态，不用静态样例或随机补值。 |

| 权重表导入 | 仅当前账户可导入；校验官方 HTTPS 来源、日期、唯一代码和 99.95%–100.05% 权重合计；不保存原始文件字节。 |
| 篮子与权重权限 | 篮子、共享、导入批次和事件影响查询均受账户权限保护；未登录请求返回 401。 |
| 离站路径 | 追加核心阅读、归档、详情和导入流程未使用页面跳转或外部链接。 |

## 差异化与重复检查

23 个窗口的追加研究职责由服务端映射分别覆盖监管/资料目录、宽基共同窗口、宏观环境、单一基准、输入完整性、利率期限、因子资料、跨资产、相对路径、再平衡观察、公司行动资料边界、计算输入、发行资料、衍生品环境等不同研究目标。受限的成分、授权指数数据库、期权链、期货曲线及可执行报价继续保持真实空状态。

## 本轮结论

未发现原内容差异。所有深化能力均为原工作区之后的独立追加；未发现离站核心路径、模拟数据替代或未授权账户数据暴露。
