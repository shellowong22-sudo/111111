# ECB 外汇参考证据台验证记录

本记录对应外汇原工作区末尾新增的、与既有固定展示分离的 ECB EXR 官方参考汇率证据台。

| 验证项 | 结果 | 说明 |
| --- | --- | --- |
| 官方端点 | 通过 | 服务器可读取 `data-api.ecb.europa.eu/service/data/EXR` 的 CSV 观测。 |
| 终端路由 | 通过 | 本地 tRPC `ecbForeignExchange.getReferenceRates` 返回 USD、JPY、GBP、CHF、AUD、CAD、CNY 的实际发布观测与 8 个最近交易日历史。 |
| 最新实际返回 | 通过 | 2026-08-25 的 USD/EUR 为 1.1662、JPY/EUR 为 185.70；返回值含观测日期与 7 日变化。 |
| 页面实际路由 | 已修正 | `/forex` 是未注册路由并显示 404；实际保留路由是 `/forex-hub`。 |
| 受控预览 | 部分通过 | `/forex-hub` 全页截图确认 ECB 工作台已挂在原外汇内容之后；截图捕获时显示“正在读取”加载态。 |
| 独立浏览器 | 受环境限制 | 浏览器沙箱在同一路由返回空白文档；该现象与此前收益率页代理异常相似，不能据此认定组件业务失败。 |

该工作台不导航至第三方网页。页面渲染服务端返回的限制文本，明确其为 EUR 基准官方参考观测，**不是**实时成交、bid/ask、订单簿或交易建议；当官方源不可用时，路由返回真实空状态，不以原页面固定数值或模拟数据替代。
