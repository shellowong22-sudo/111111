# 外汇官方利率公告归档与公开数据时效设计

## 目的与原内容边界

本轮能力只在外汇原工作区与既有公开研究层之后追加。归档不是预测、交易信号或第三方跳转目录；它在终端内保存并显示经官方页面核验的政策决议字段。没有可结构化读取的官方公告时，不创建样例事件，不以新闻摘要或市场预期替代。

每个来源在配置中拥有经人工核验的 URL 对应决议日期。解析器先使用此稳定来源日期，再从公告正文核对政策行动和利率字段；它不会把反对票、个别委员偏好或网页内的其他日期作为主决议日期或实际政策行动。

上述事实在 **2026-08-21** 读取。终端保存公告发布日期、决议日期、利率区间或单一利率、变化基点、投票、原始官方 URL、来源机构和受限长度的官方摘要；不会保存或展示外部网页上的完整长文替代正文。

## 时效健康口径

健康面板对每个公开外汇序列展示以下不插补字段：最近实际观察日期、上游页面/响应读取时点、计算延迟小时数、读取结果和历史点数。延迟定义为 `读取时点 − 最近实际观察日期 00:00 UTC`，因此它反映公开历史观察的时间距离，**不是**实时市场行情或上游承诺的 SLA。H.10/FRED 非交易日和发布滞后会自然显示为延迟，不标记为“缺失”。

当读取失败、观察日期缺失、上游返回无数值或来源不在白名单内，状态为不可读/无实际观察；终端不以旧缓存冒充实时数据，也不估算延迟。源记录包括 [FRED DEXUSEU](https://fred.stlouisfed.org/series/DEXUSEU)、[FRED DTWEXBGS](https://fred.stlouisfed.org/series/DTWEXBGS) 与 [美国联邦储备委员会 H.10](https://www.federalreserve.gov/releases/h10/current/)。
