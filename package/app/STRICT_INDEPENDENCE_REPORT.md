# 严格独立性验证报告

## 结论

严格发行源码树的运行时代码、客户端代码、共享代码、`package.json`、`pnpm-lock.yaml`、根 Vite 配置、独立 Vite 配置和环境模板，已执行平台域名、凭据变量、RPC 头、存储路径、构建插件和 UI 品牌扫描。阻断项为 **0**，平台品牌词为 **0**；生产构建产物的阻断匹配文件为 **0**。

## 已移除内容

严格发行树不包含平台 Vite 插件、平台调试收集目录、平台 OAuth RPC 类型、平台图像/语音/地图服务端封装、平台对象存储代理和未使用的平台登录对话框。原兼容模式的 SDK、Heartbeat、Data API、LLM、通知与对象存储均已改写为独立实现。
