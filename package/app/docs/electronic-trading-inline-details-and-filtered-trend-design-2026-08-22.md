# 电子交易行内详情与筛选趋势设计

行内详情仅显示当前账户私有订单聚合字段和同一账户的审阅记录。可显示订单/交易 ID、标的、方向、最新事件时间和状态、执行与可计算执行数量、可计算执行名义额、方向性不利偏离、首笔成交时延、场所、经纪商、策略、路由以及审阅状态、备注和更新时间。详情在当前表格行下方展开，不创建路由，不修改导入事件，也不向原交易通道发送指令。

趋势图使用当前筛选结果包含的订单 ID，回连这些订单已导入的逐笔执行事件。每一个日期只对提供正执行价和正执行数量的事件累计 `executionPrice × executionQty`。缺失价格或数量的执行事件保留在缺失计数中，不以市场数据推断。由于数据模型不强制币种，图表和指标将其标示为“可计算执行名义额”，明确不跨币种换算。
