# 全终端深度功能与静态内容审计基线

## 审计目标与保护边界

本审计以**不改写原有菜单、名称、文字、字段、顺序和交互语义**为前提。任何后续功能只允许进入其所属的原窗口；不得增加目录级通用面板、跳转第三方页面，或把样例、随机、缓存展示伪装成实时市场事实。

审计范围包括主终端的全部一级业务域、二级菜单及其打开的窗口：市场（主权债、信用债、抵押债、货币市场、地方债、优先股）、权益与衍生品（股市、大宗商品、指数、外汇、衍生品）、通讯与社区、新闻与研究、经济分析、专业应用（投资组合、定价风险、交易委托、电子交易、STP、交易账簿、行业分组）、平台工具、个性化工作台与帮助入口。

## 当前可复用但不可泛化的真实数据能力

项目现有服务层已包含 Yahoo 历史行情/公开新闻、FRED 宏观时间序列、World Bank 宏观指标与美国财政部公开拍卖资料。后续使用时必须按业务域决定是否适配：例如 FRED 可支撑宏观环境、利率和部分风险因子，不应被伪装为个券订单簿、交易执行或公司新闻；Yahoo chart 可以提供证券 OHLCV，不应被伪装为交易所可执行报价或完整公司公告库。

## 分批验收方式

每个候选窗口将按以下顺序处理：先提取原内容保护基线，再确认当前字段和数据是否静态或重复；随后选择适合该业务域的公开/内置来源或保留真实不可用状态；最后增加窗口内筛选、对比、来源定位与交互测试。对交易、订单、账户和私人持仓类窗口，不会在没有授权数据源的情况下创造虚构订单、仓位、成交或客户内容。

第一批聚焦新闻与研究、经济分析、投资组合与风险、定价与风险、电子交易五个固定内容密度最高的业务域；每个域先从一个代表性窗口验证完整模式，再继续扩展到同域其他窗口，避免复制相同的“通用说明卡”。
