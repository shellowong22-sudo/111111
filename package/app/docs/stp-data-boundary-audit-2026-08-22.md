# STP 数据边界审计

原 `STPProcessing` 页面及 `server/routers/stp.ts` 已审计。原服务端路由公开暴露，并以 `generateTrades`、`generateSSIs`、`generateAlerts` 等函数及 `Math.random()` 生成交易、标准结算指令、结算告警、净额和监管报告样本。它们可保留原页面的既有演示功能，但**不得**用于新增账户私有指标、队列、异常、结算率、对手方或监管结论，也不得描述为实际经纪商、托管行、交易所、清算机构或监管处理状态。

追加层只可使用用户主动导入、账户隔离并规范化的 STP 生命周期记录。拟议字段覆盖处理事件 ID、指令/交易 ID、事件类别、事件时间、工具、方向、金额/数量、货币、对手方、处理阶段、结果状态、失败代码和文本说明。原始导入文件不保存；新增层不向原路由或外部结算/托管/监管通道提交指令。无导入记录时必须保持真实空状态。
