# 投资组合风险深化：设计依据

本次深化仅追加于原投资组合工作区之后。风险研究只使用当前登录账户主动保存的标准化债券持仓快照、用户明确输入的冲击参数与账户私有限额；终端不跳转第三方网页，不生成替代持仓，不将压力测试输出表示为发生概率或交易指令。

| 设计原则 | 终端内实现边界 | 依据 |
| --- | --- | --- |
| 压力测试补充而非替代统计风险模型 | 以平行、陡峭化、蝶式冲击计算久期—凸性敏感度，并显示方法与未覆盖风险 | [BIS 压力测试执行摘要](https://www.bis.org/fsi/fsisummaries/stress_testing.htm) |
| 严重但合理的情景与数据质量并重 | 仅对账户主动保存的持仓快照出具结果；无快照保持空状态 | [BIS 压力测试执行摘要](https://www.bis.org/fsi/fsisummaries/stress_testing.htm) |
| 敏感性测试与情景测试有不同用途 | 允许用户选择冲击形态和幅度，结果不推断情景发生概率 | [FRBSF：压力测试是风险模型的有益补充](https://www.frbsf.org/research-and-insights/publications/economic-letter/2005/06/stress-tests-useful-complements-to-financial-risk-models/) |
| 数据治理与可追溯性 | 账户私有限额、研究档案和超限结果保存为可检索记录；保留输入快照标识与生成时点 | [SEC Data Library](https://www.sec.gov/data-research/sec-markets-data) |

这些资料仅作为功能设计与方法边界参考；终端用户界面不包含向其跳转的外部链接。

## 授权数据覆盖审计（2026-08-22）

| 风险维度 | 终端可用数据 | 使用边界 |
| --- | --- | --- |
| 信用利差 | 既有 `creditResearch.getOasSnapshot` 读取的 FRED / ICE BofA 指数级日度 OAS：IG、AAA、AA、BBB、HY | 仅用于评级桶级市场参考；不将其表示为单券、可成交价差、CDS 点位或投资组合的实际信用利差。 |
| 单券信用与 CDS | 当前未接入获授权实时单券报价、TRACE 逐笔成交、CDS 点位、评级迁移或指数成分 | 保持明确不可用状态，不以公共指数、静态样本或合成价格替代。 |
| 流动性 | 当前无获授权的账户持仓级可成交报价、订单簿、成交量或交易成本数据 | 仅根据用户主动输入的持仓字段检查流动性数据是否已授权和完整；缺少字段时显示不可评估，不生成流动性评分。 |

终端内信用利差和流动性维度将随每份研究档案保存读取时点、来源说明及适用边界；任何不可用数据维度均显示明确空状态。
