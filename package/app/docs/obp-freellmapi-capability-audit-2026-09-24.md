# OBP-API / freellmapi 归位核验（2026-09-24）

此记录仅说明这两个用户提供的压缩包；不把「仓库代码存在」「目录可读」「服务可用」「金融数据实时」混为一谈。

| 压缩包 | 实际能力 | 当前对应已有入口 | 已验证的边界 |
| --- | --- | --- | --- |
| `OBP-API-develop.zip` | 开放银行 API 服务端；银行账户、交易等个人数据依赖机构接入与授权 | 暂无可安全推送的现有证券行情功能 | 公共沙盒 `/obp/v5.1.0/banks` 可返回测试环境目录，但不能作为生产银行账户、全球个股、期权、期货或实时行情；未引入终端 |
| `freellmapi-main.zip` | 自部署的 OpenAI 兼容 `/v1` AI 请求网关 | 已有 `/admin/ai-management?tab=models` 的模型状态及原有 AI 调用链 | 后端支持单独的 `FREELLMAPI_BASE_URL`、`FREELLMAPI_API_KEY`、`FREELLMAPI_MODEL`；只有服务运行、已设置统一密钥且模型目录成功返回时才显示目录已连接；模型结果不是金融事实 |

前端不新增模块/页面，不用这两个仓库替换股市 7/14/17/18/20/24/26/30/31、大宗商品 12/13/14、指数 7/13/14/17、衍生品 1/4/10/11/14/15/18/22、新闻与研究 13/15/16/17/20/26/29、经济分析 1/9/18/19 的占位槽。编号不决定数据归属。两个包都没有能直接替换这些具体证券、商品、指数、宏观功能的真实数据接口或对应金融子页面。

实际配置方法：自部署网关并向该网关加入你自己获许可的模型密钥；在 Finance Hub 后端设置 `FREELLMAPI_BASE_URL=http://127.0.0.1:3001/v1` 和仅保存在服务器上的 `FREELLMAPI_API_KEY`。如已设置 `LLM_BASE_URL`，原有配置优先。不要把密钥放进前端、聊天或压缩包。当前未配置网关或密钥时，后端不请求它、不生成替代响应，模型状态显示未配置。

OBP 若日后要接真实银行账户，必须先选定生产银行/实例、获得合法的应用认证和账户主体授权，再单独确定现有银行业务功能的所有权与字段白名单。沙盒列表不是这种授权，也不应自动推送到市场行情面板。
