# 免费公开证券新闻来源核验

## 候选来源与实际结果

本轮核验使用 Yahoo Finance 的公开搜索端点，而不使用当前会话中已返回不可用状态的内置付费代理。实际读取地址为：

```text
https://query2.finance.yahoo.com/v1/finance/search?q=<SYMBOL>&quotesCount=0&newsCount=12
```

2026-08-25T06:42:02Z，对 `000001.SZ` 的请求返回 HTTP 200 和 `news` 数组，但返回条目的 `relatedTickers` 并不包含 `000001.SZ`；这些条目因此不能被展示为“平安银行新闻”。2026-08-25T06:42:02Z 至 06:42:xxZ 之间，对 `AAPL` 的同类请求返回多个包含 `relatedTickers: ["AAPL", ...]` 的实际新闻条目。终端只显示 `relatedTickers` 包含所选证券 Yahoo 查询代码的条目，避免把市场泛新闻或其他公司的标题错误归属给所选证券。

## 代码与来源规则

导入清单的原始证券代码保持不变。为查询公开端点，只有美国代码末尾的 `.O`、`.N`、`.A` 或 `.B` 会在**查询层**移除该后缀，例如清单中 `AAPL.O` 以 `AAPL` 查询；页面与数据库仍展示、保存 `AAPL.O` 原值。其他国家/地区的原始代码不作猜测性改写。

每条新闻只保存并显示来源返回的标题、发布者、发布时间和来源地址定位。终端内的“白话解读”是基于标题主题的短篇原创说明，不复制正文、不替换同义词以伪装成原文，也不自动跳转到外部网页。没有关联条目、端点不可用或返回异常时，终端显示明确空状态。

“白话解读”不再依据标题关键词将条目归类为业绩、分红、融资或并购消息。因为标题和元数据不足以支持该类事实判断，当前固定为事实线索说明：该条目与证券代码关联，但必须通过来源页面核实事件细节、财务含义或价格影响。这一处理保留用户需要的口语化提示，同时避免从不完整信息得出推断性结论。

为避免所有条目都显示相同说明，终端会为每条新闻摘取其自身标题的短引导语，并显示“这条标题在谈‘…’”。该短引导语只是帮助阅读标题线索，不是正文复写、事实提炼或结论；标题不足以支撑事实判断时，紧随其后的口语化提示会明确要求以来源页面核实。

终端还展示该条来源实际返回的 `type` 和 `relatedTickers`。例如来源标记为 `STORY` 时，白话线索写明其是文字报道；对 `VIDEO` 则写明其是视频报道，并列出最多四个来源关联代码。这些均是来源元数据，而不是系统对新闻正文或事件影响的判断。实际 AAPL.O 返回的多条新闻已验证每条标题线索、类型和关联代码各自不同。

## 公开历史行情回退

当原内部 Yahoo chart 通道返回额度耗尽或其他不可用结果时，行情层会服务端回退到 Yahoo Finance 的公开 `query2` chart 端点，并用浏览器标识请求。该回退只在原通道没有可解析历史点时触发；来源字段明确为 `Yahoo Finance public chart`，并继续保存查询时间、市场观测时间、价格、涨跌、币种、历史 OHLCV 和可用状态。美国导入代码仅在查询层移除 `.O/.N/.A/.B` 后缀，例如 `AAPL.O` 查询 `AAPL`，终端清单和主数据中的原始代码不变。

2026-08-25 对 AAPL.O 的实际接口和浏览器核验均返回 21 个日频历史点、价格 310.34 USD、收盘价图和成交量图。该公共端点仍可能受覆盖范围、临时限流、市场代码可识别性或上游可用性影响。若内部通道和公共回退都不可用，终端保留真实不可用状态，不使用缓存样例、合成价格、替代证券或虚构图表。

## 边界

该端点提供公开搜索结果，不能保证每个市场、每个证券或每个时点均有覆盖；因此它不是交易所公告的完整替代，也不是专业新闻授权库。对于无关联返回的证券，界面应保持“无可验证新闻”状态，而不以公司名相近、市场热门或历史样例文章代替。

## 终端接口复核

开发服务重启后，`equityListings.news(countryCode=US, symbol=AAPL.O)` 返回 `available=true`、`source=Yahoo Finance public search`、实际发布者字段和逐条 `plainLanguage` 原创解读。对 `equityListings.news(countryCode=CN, symbol=000001.SZ)`，来源虽然返回了搜索新闻，但没有条目的 `relatedTickers` 包含该代码；接口返回 `available=false`，未显示任何无关条目。这两个结果分别验证了实际成功路径和相关性保护路径。
