# 电子交易账户私有列表筛选与加载体验审计

**范围：** `ElectronicTradingDataList.tsx` 及其受保护的账户私有 tRPC 查询。

## 结论

列表仅接收当前登录账户已导入执行批次的聚合订单记录。关键词、买卖方向、最新事件、场所、经纪商、策略、路由、审阅状态、预警状态和时间范围均在浏览器中对已获取的账户私有记录进行筛选；排序字段包括最新事件时间、订单、标的、执行数量、加权不利偏离和首笔成交时延。没有调用原 `trading` 演示数据接口，也没有外部链接或浏览器跳转。

加载体验区分首次读取、后台刷新和筛选/排序应用中三类状态。无导入数据与无筛选结果分别有明确说明，清除筛选和刷新均有可操作控件。刷新使用现有受保护 tRPC 查询，仍受账户所有权约束。

原电子交易页面和 32 个既有面板不在本次变更范围内；列表继续位于原工作区和既有账户私有研究层之后。
