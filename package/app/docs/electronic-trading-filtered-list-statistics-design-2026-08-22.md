# 电子交易筛选列表统计、搜索与导出设计

所有计算的输入均为当前账户主动导入的规范化执行事件聚合而成的订单记录，并在浏览器端套用当前筛选条件后再计算。原电子交易工作区的演示订单、报价、成交、损益和风险数据不参与任何统计、搜索或导出。

| 面板指标 | 口径 | 边界 |
|---|---|---|
| 筛选订单数 | 当前筛选输出的唯一订单数 | 不等同于原工作区挂单数 |
| 执行数量 | 当前筛选订单的已导入执行数量之和 | 未提供数量的事件不推断 |
| 可计算执行名义额 | 已导入执行价乘以正执行数量的合计 | 不跨币种换算；资产币种未知时不作为货币总额陈述 |
| 可计算成交订单 | 至少一笔成交具有参考价、执行价和正数量的订单数 | 缺字段保持不可计算 |
| 超阈值订单 | 按账户私有偏离/时延阈值识别的订单数 | 不构成自动交易或风险指令 |
| 加权不利偏离 | 以可计算成交数量加权的方向性偏离 | 买入为执行价减参考价，卖出为参考价减执行价 |

全局搜索与现有筛选相交，检索订单/交易 ID、资产、场所、经纪商、策略和路由字段。导出仅包含当前筛选输出：CSV 使用 UTF-8 BOM，Excel 使用真实 `.xlsx` 工作簿，二者均写入生成时间、筛选范围和账户私有数据边界；不包含原始上传文件、凭据、其他账户记录或原工作区演示数据。
