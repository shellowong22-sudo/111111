# 行业分组 22 个功能窗口：逐项窗口内升级审计

## 不可变范围

`IndustryGroupMenu.tsx` 的编号、功能码、名称、分组、顺序与点击分派不得改变。`IndustryGroupAnalysis.tsx` 的字节级基线保持不变。原功能窗口可保留其标题、关闭行为与既有布局；新增能力必须位于对应窗口内容区，而非主目录或独立全局模块。

## 实施约束

每个窗口必须显示其自己的研究目的、指定参考序列、专属筛选或录入字段、刷新状态和数据边界。对于没有可授权结构化来源的事实域，工作流必须接收并校验用户有权导入的来源定位；不能通过随机 KPI、网页跳转、新闻摘要或推测性数字伪造功能完整度。
