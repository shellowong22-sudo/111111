# 全球股票清单导入审计

## 导入范围与保真规则

本次仅使用用户上传的 `.xlsx` 工作簿作为清单来源，不通过外部行情源补写、翻译、替换或推测任何证券代码与证券名称。系统将代码和名称原样保存，并另行记录国家、交易所、来源文件、来源工作表、原始行号和工作表内容 SHA-256，以便逐条追溯。

目标表为 `equity_listings`。它与已有 `market_data` 行情表分离：前者保存股票清单原始事实，后者仍保存可用的价格、涨跌和成交量。因此，本次导入不会将 `0` 或其他占位行情写入用户提供的股票清单。

## 重复与异常处理

多个欧洲工作簿包含相同国家工作表，两个以色列工作簿也包含相同内容；系统依据每张工作表的代码与名称序列 SHA-256 只选择一份规范来源，不重复写入。阿联酋“迪拜金融市场”清单是“阿联酋全部股票”清单的部分重叠，按国家代码与证券代码去重后保留 175 条联合清单。`全部港股.xlsx` 内附带的一行 `全部A股` 数据与 `全部A股.xlsx` 中同一代码和名称相同，也按同一规则去重。

所有工作簿的有效代码和名称单元格均为字符串；最大代码长度为 17，最大名称长度为 75，未发现首尾空白。目标字段分别为 `varchar(32)` 与 `varchar(128)`，不会发生截断。

## 可读取接口与核验

新增只读接口 `equityListings.countries` 用于返回国家及数量，`equityListings.list` 支持按 `countryCode`、代码或名称分页查询。全量核验将数据库中每一条记录的国家、国家代码、交易所、证券代码、证券名称、来源文件、来源工作表、源行号和 SHA-256 与工作簿重建结果逐字段比较；核验结果为 43,085 对 43,085，缺失、额外和字段不一致均为 0。

用户可从主终端的“股市”菜单打开 `WEI 全球股票指数`，或直接访问 `/terminal?module=stocks&open=wei`。在该原窗口内部选择“全球股票清单”标签，即可按国家/地区筛选、按代码或名称检索，并以每页 50 条浏览已导入记录。

在清单中选择已导入证券后，终端会向服务端请求该证券在 `Yahoo Finance chart` 数据源中实际可用的日频 OHLCV 观察，并将来源、查询时间、市场观测时间、可用状态和不可用原因写入 `equity_quote_snapshots`。窗口内的价格折线和成交量柱图只在返回实际历史观察时呈现；查询失败、无覆盖或无历史时明确显示不可用原因，不以随机数据、固定示例、静态价格或第三方页面跳转替代。

清单行与详情区采用同一 WEI 窗口内的主从布局：左侧保留国家筛选、名称/代码检索与分页，右侧立即显示所选证券的真实行情、来源与时间。详情区还提供按需“读取新闻”动作，仅读取实际返回的 `Yahoo Finance news` 标题、发布者、发布时间与来源地址定位；无返回或源不可用时保留明确空状态，不生成摘要、情绪或替代新闻，也不自动离开终端。
