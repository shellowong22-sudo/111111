# 优先股 SECF / FIT 分析工具整改

## 真实入口确认

Terminal → PreferredStockPreservedModule → ResearchModuleWorkspace 的 tools 属性，分别传入 PFSECFPanel / PFFITPanel。不是只修改其他未接入路由的同名面板。

本轮直接重写这两个导出函数的实现并保留导出、原菜单和关闭行为。旧随机函数主体已从文件移除，不以 CSS 隐藏或警告作为替代。

## 职责与深度

| 功能 | 数据研究职责（保留） | 分析工具整改后职责 |
| --- | --- | --- |
| SECF | SEC 主体目录识别与行业身份 | 当前账户实际条款的规则筛选：票面分配率、首赎保护期、条款时效、来源证据、CIK；每条结果可进入逐项规则明细，附筛选状态分布、排序、分页、CSV |
| FIT | 执行前资料完备性闸门 | 用户提供的已发生成交逐笔复核；有向价格差额+费用；分证券/币种/委托筛选；成本组成图、累计成本路径与原始表；CSV |

SECF 不再次复制 SEC 目录，不把票面分配率当股息收益率、不生成评级或买卖信号。规则未启用/字段缺失/不符合分开处理；未来观察日期被标记为前视问题。

FIT 不生成报价、成交、盘口、暗池率、执行效率或假成功。它只计算明确有来源的输入记录：

- 买入价格差额 = (成交价 − 决策基准价) × 数量。
- 卖出价格差额 = (决策基准价 − 成交价) × 数量。
- 总成本 = 有向价格差额 + 明确费用。
- 成本基点 = 总成本 ÷ 决策基准名义金额 × 10,000。
- 单边成交均价按成交量加权；混合买卖不显示一个混合均价。

相同委托/成交ID重复、委托身份冲突、时区缺失、非正价格数量、缺费用、缺来源均原子拒绝，不替换已载入数据。不同证券或不同币种不聚合成本。

## 数据边界

- SECF 只查询当前登录账户已导入条款，60秒重新读取，不是完整全球优先股实时行情。
- FIT 输入仅本会话，未经用户操作不写数据库、不发送订单。自动经纪商/执行系统接入未配置。
- PSCH 保留已有现金流DCF能力，FIT不复刻第二张现金流/定价表。
