## 真实接入边界

- 直接适配的七个数据合同是 TWSE 股票快照 `equity.twse.snapshot.v1`、台湾股票估值 `equity.twse.valuation.v1`、TAIEX 指数快照 `index.twse.taiex.snapshot.v1`、黄金 PLN/克日频参考价 `commodity.pl.gold.nbp.daily.v1`、USD/PLN 日频中间参考汇率 `fx.pl.usd-pln.nbp.daily.v1`、不含 USD 的 NBP A 表多币种日频参考汇率 `fx.pl.multi-pln.nbp.daily.v1`，以及 CNB/CZK 多币种日频参考汇率 `fx.cz.cnb.daily-reference.v1`。后台逐合同显示状态，不把股票估值、商品参考价或外汇中间价相加成“实时行情”。
- 压缩包的 `get_tw_all_listed_stocks()` 名称与实际返回不符：`BWIBBU_d` 是有观察日、市盈率、市净率、股息率的估值表，不是上市证券目录。实际路径 `exchangeReport/BWIBBU_d` 已核验；缺失市盈率不推算，`ClosePrice` 不进入估值合同的前端字段。该日频表不是逐笔实时行情。
- 当前五项都能在 `market_data_observation_history` 保存；数据库缺席时写入 `.runtime/fincept-public/history.json`，重复内容不新增记录，修订保留历史版本。数据库定时任务已启用；无数据库启动时由限定的本地轮询继续采集。磁盘或数据库的长期保留仍需运维备份，不能保证外部服务永不中断。
- 压缩包 `public_apis_finance_data.py` 中的 NBP 黄金与汇率能力使用公开接口，无需密钥。2026-09-29 实测：黄金最近观察日 2026-09-29、512.64 PLN/克；USD/PLN 最近观察日 2026-09-28、3.8478 PLN/USD。两者各归档 30 个日频观察，第二次采集各拦截 30 个重复。页面只收到业务值、货币/单位、观察日；参考价不用于推断买价、卖价、市场成交价或逐笔实时价格。
- 同一脚本的 NBP A 表接口按 30 个发布日归档 31 个非美元货币对，共 930 条观察，唯一合同只落入既有 `FXC 汇率矩阵`。2026-09-29 实测最新发布日为 2026-09-28；首次新增 930、复采新增 0 且拦截 930 个重复。`USD/PLN` 继续由原合同负责，篮子显式剔除 USD；前端逐行显示货币对、参考值、观察日和币种单位，买卖报价缺失时保持空值。
- 同一脚本的 CNB 接口读取公开 `daily.txt` 定盘表，2026-09-29 实测返回 30 个货币对，最新公开观测日为 2026-09-25；`CZK/每单位外币` 的值由发布的数量和定盘价确定性归一化。首次同步新增 30 条，重复同步按同一合同、货币对和观察日拦截重复；接口不可用时保持不可用，不生成替代值。
- 首页真实菜单入口：`权益与衍生品 → 外汇 → 第 6 项 FXC 汇率矩阵`，直达 `/terminal?open=fxc&module=forex`。原 FXC 矩阵、基准币种选择、列表、CSV 和公开日频查询保留；归档 PLN 观察扩展原功能的币种集合并直接进入矩阵与列表，点击货币对后在原有详情查看同日有效的历史序列，不再增加独立展示区；`/forex-hub` 仍是既有外汇中心完整视图，不另行采集或复制入库。
- FXC 原矩阵在原有日频观察缺失时，仅以相同 NBP 发布日的 PLN 参考腿或 CNB 发布日的 CZK 参考腿进行交叉换算，并标注“日频参考”；日期不一致、未覆盖或远期档位保持空值，不能把换算值称作可执行即期/远期报价。
- 其他类别已有可验证的应用内适配器时，不再复制 Fincept 的 Python 脚本，避免同一数据进入多个功能。
- 后台将这两类明确分开：`压缩包直接适配` 只表示当前服务实际执行了压缩包对应连接器；`既有平台适配器` 表示页面已有真实合同复用，不能计入压缩包直接接入。
- 压缩包中的 `fincept-qt/src/screens` 和 `fincept-qt/src/services` 是真实 Qt/C++ 前端与服务源码。后台的“前端功能盘点”会列出主要界面域、源文件数量及现有入口；标为“仅盘点”的域没有对应 React 数据合同，因此不会被伪造为已接入，也不会新增页面。
- Fincept 的 AKShare Python 包装器依赖本机 `akshare`。当前运行环境没有该依赖，因此不能把其 100 多个脚本标记为“已连接”；后台能力面板会显示为“已有真实适配”或“依赖未满足”，不会伪造成功。
- 前端只接收业务字段、观察日期、标的名称/代码和时效边界；内部地址、密钥、执行命令、采集字段和脚本路径不会通过公共数据流发送。

## 自动链路

`定时执行 → 字段清洗 → 唯一功能归属 → SHA-256 指纹去重 → 持久归档 → 既有页面读取`

2026-09-29 核验：估值接口返回 1,081 条可保存观察，其中 871 条有可显示的市盈率；相同数据第二次归档为新增 0、重复 1,081。EQS 的“多维筛选 → 市盈率≤”使用对应证券的已发布估值，行内显示估值观察日；后台入口为“管理后台 → OpenBB → Fincept 能力归属 → 直接适配接口逐项核验”。这些计数是当次测试结果，不代表后续永远保持可用。
