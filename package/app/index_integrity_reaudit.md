# 指数模块逐项完整性复核

## 原内容与顺序

IndexHub 路由壳和全部 23 个原指数面板继续由 `server/indexProtection.test.ts` 的 SHA-256 指纹锁定。保留容器先渲染原页面，再顺序追加公开研究层、成分变更归档与仅在 CIX/CIXB 呈现的账户篮子协作区；原菜单、原字段、原窗口标识、原面板顺序和原交互均未改写。

## 逐项功能与差异化

| 复核范围 | 结论 | 终端内边界 |
| --- | --- | --- |
| 23 个原窗口 | 已按 `index_differentiation_matrix.md` 逐项映射 | 每个窗口使用不同的公开资料职责，不以同一图表重复替代 |

## 加载、错误、空状态与权限

研究层、公开归档和篮子读取均有独立加载状态。官方公告不可读、不可解析或无归档记录时，时间轴显示真实空状态；缺少事件日成分权重时，悬停提示说明资料边界而不显示计算值。篮子、成员目录、共享和审计接口均为受保护接口；未登录读取篮子接口返回 HTTP 401。

## 核验结果

已完成公开归档接口实读、CIXB 追加层视觉核验、低内存前端打包、指数专项保护与协作回归。核心终端路径不以外部跳转完成数据查看；官方来源只作为服务端资料读取和终端内可追溯标识。完整回归将在本轮发布前再次执行。
