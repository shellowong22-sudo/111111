# 外汇模块差异化深化矩阵

## 公开数据边界

终端内追加研究使用 FRED 转载的美国联邦储备委员会 H.10 日度外汇序列与美元指数。官方序列页面表明，`DEXUSEU` 是“美元/欧元”、日度、非季调序列；2026-08-14 的观察为 1.1581，页面更新时间为 2026-08-17 16:14 CDT。`DTWEXBGS` 是以 2006 年 1 月为 100 的名义广义美元指数；2026-08-14 的观察为 118.9028，页面更新时间相同。美联储 H.10 周表列示同一周的双边汇率与广义、先进经济体及新兴经济体美元指数，并明确广义指数是美元对广泛主要贸易伙伴货币的加权平均。已核验的可读序列包括美元兑欧元、英镑、澳元，及日元、加元、新加坡元、韩元等以美元为基准的序列；同时使用名义广义美元指数。所有系列均为公开历史观察，不是实时可执行报价、银行点差、订单簿、做市深度、官方 fixing、期权隐含波动率、交叉货币基点差或预测。

| 来源 | URL | 用途 |
| --- | --- | --- |
| FRED `DEXUSEU` | https://fred.stlouisfed.org/series/DEXUSEU | 日度美元/欧元历史观察、方向与单位核验。 |
| FRED `DTWEXBGS` | https://fred.stlouisfed.org/series/DTWEXBGS | 日度名义广义美元指数。 |
| 美国联邦储备委员会 H.10 | https://www.federalreserve.gov/releases/h10/current/ | H.10 周度发布、双边汇率与美元指数定义。 |

## 逐入口职责

| 原入口 | 追加研究职责 | 公开数据/真实边界 |
| --- | --- | --- |
| FXIP | 宽基市场概览 | 主货币共同日期与美元指数 |
| FXDS | 数据可读性矩阵 | 每个可读序列的日期、单位、历史深度 |
| FXTF | 代码与报价方向校验 | H.10 单位、倒数换算及当前可读性 |
| FXC | 交叉汇率矩阵 | 同日美元基准实际观察推导 |
| WCR | 主要货币区间路径 | 实际归一化日度路径 |
| WVOL | 已实现日度范围 | 不将历史变化伪装为期权隐含波动率 |
| XCCY | 基点差资料边界 | 未授权公开结构化交叉货币 basis 时真实空状态 |
| GMM | 宏观驱动环境 | 广义美元、联邦基金、2 年/10 年国债公开观察 |
| FXSW | 策略输入审计 | 只展示可读公开输入，不产生策略建议 |
| XDSH | 观察屏覆盖 | 主要货币最新可读性与更新日期 |
| FXFC | 预测资料边界 | 不生成价格预测或目标位 |
| WCRS | 区间变动排名 | 可读货币的同日区间实际变动 |
| ECMI | 日度变化定位 | 实际日变化，不归因于具体新闻冲击 |
| MYQ | 自选资料边界 | 未新增账户自选表时明确空状态 |
| ALLQ | 全部交叉报价矩阵 | 同日有效观察推导，缺口不插补 |
| FRD | 远期输入覆盖 | 即期和公开利率输入状态，不伪造远期曲线 |
| OVML | 期权资料边界 | 无免费可读隐含波动率链时真实空状态 |
| BFIX | 定价资料边界 | 无授权 fixing 时不以 H.10 代替 fixing |
| FXFA | 利差输入观察 | 仅显示实际公开利率输入，非套利回报建议 |
| GP | 单一货币路径 | 可选主货币历史图与区间统计 |
| FIRS | 官方来源更新状态 | H.10/FRED 最新实际观测与读取状态 |
| TOP FX | 新闻资料边界 | 不用静态新闻或跳转替代结构化资料 |
| STNI | 数据传输状态 | 已读取序列与更新日期，不制造新闻提醒 |
| RES | 研究资料目录 | 终端内可读序列覆盖与限制 |
| BICO | 分类资料覆盖 | 主要货币、美元指数、利率环境分类 |
| MARS FX | 可执行交易资料边界 | 无免费可执行报价、订单或交易权限时真实空状态 |

## 路由审计

主终端已有 21 个外汇原窗口映射；MYQ、OVML、GP、TOP FX、RES、BICO、MARS FX 等原菜单入口未提供独立原窗口。后续会以独立的追加式资料边界工作区承接这些入口，不创建伪造的原窗口或示例交易数据，并保持菜单文件与已有原面板零改动。
