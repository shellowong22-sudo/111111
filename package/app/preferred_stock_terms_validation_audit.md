# 优先股条款导入与趋势筛选验证审计

**核验日期：2026-08-20**

## 批量导入与覆盖报告

条款导入采用账户级 CSV 工作流：先在浏览器解析，再由服务端统一校验，最后通过受保护的账户接口写入当前条款库。空白模板只包含字段名称，不包含样例证券或模拟条款。导入前显示可导入、拒绝和警告行；确认导入后返回导入数、更新数、拒绝数、警告数及自动字段覆盖完整性报告。原始 CSV 不写入数据库，数据库只保存用户确认的结构化条款、导入批次元数据和覆盖汇总。

| 校验项目 | 验证结果 |
| --- | --- |
| 固定分配条款条件字段 | 通过：固定/固定转浮动缺少分配率时拒绝导入 |
| 浮动分配条款条件字段 | 通过：浮动/固定转浮动缺少参考指数、加点或重设频率时拒绝导入 |
| 重复标识 | 通过：同一 CSV 中的重复 `security_identifier` 拒绝导入 |
| 账户级幂等更新 | 已实现：按账户和证券标识更新当前条款快照，并记录导入批次 |
| 覆盖报告 | 通过：输出核心、条件、推荐字段覆盖率、缺失字段计数和分配类型完整性 |

## SEC 与 FRED 趋势筛选

SEC 趋势面板可按 CIK、日期窗口、表单、事件类别和主文件名关键词筛选本终端读取的实际申报目录，并按月绘制申报数量。FRED 趋势面板可按利率/信用类别、日期窗口、自定义日期、具体序列和当前可读状态筛选服务器返回的真实历史观察。实测环境接口对 7 个序列均返回 2026-08-18 观察日期及 `available` 状态；实测 CIK `0000070858` 的 SEC 目录返回 2026-08-20 和 2026-08-19 的实际 `424B2` 元数据。两类趋势都留在本终端，不提供离站核心阅读路径。[1] [2]

优先股原始菜单及三份 PF 原面板的 SHA-256 指纹与先前保护基线一致；新增导入和趋势组件未发现 `href`、`window.open` 或 `location.href` 调用。PSCH 根路径深链视觉核验继续显示原工作区保留横幅和未改写的原面板。完整回归通过：**68 个测试文件、380 项测试**。
