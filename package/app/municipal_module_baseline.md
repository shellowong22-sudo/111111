# 地方债不可变功能基线

本基线以 `LocalBondMenu.tsx` 与 `Terminal.tsx` 为准。地方债保留 **21 个菜单入口**、既有编号、名称、顺序、原面板、原字段、原图表与原交互；后续仅允许将新增层渲染在原面板之后，禁止替换、删除、重命名或改写原面板。

| 编号 | 代码与名称 | 原面板 | 原有关键研究内容及交互 | 外链边界 | 允许追加的终端内挂载点 |
| --- | --- | --- | --- | --- | --- |
| 1 | 证券与功能说明 | `MuniSecInfoPanel` | 地方债信息与功能说明、页内状态交互 | 无 | 字段口径与来源覆盖卡 |
| 2 | MSRC 地方债检索 | `MSRCPanel` | 评级分布、迁移趋势、地区比较、选项卡切换 | 1 个既有链接，不改动 | 真实来源状态与检索口径对照 |
| 3 | SMUN 地方债发行人检索 | `SMUNPanel` | 发行人筛选、选择、财务健康与偿债计划图表 | 无 | 发行人公开财政资料覆盖与空状态 |
| 4 | AAA BVAL地方债AAA曲线 | `AAAPanel` | 曲线、历史走势、AAA/UST 比值与原有分析标签 | 无 | 税收等价收益与官方基准观察 |
| 5 | BTMM 国债与货币市场 | `BTMMPanel` | FRED 短端参考、国库券期限结构与融资核验 | 无 | SLGS/国债曲线交叉期限快照 |
| 6 | PICK 地方债发行 | `PICKPanel` | 周度发行、超额认购、定价让步与发行人选择 | 无 | 官方发行资料覆盖与日历研究层 |
| 7 | MBWD 地方债买价询价 | `MBWDPanel` | 市场深度、期限×板块流动性、执行分析 | 无 | 报价授权状态与无授权真实空状态 |
| 8 | CDRN 商议承销日程 | `CDRNPanel` | 承销商排名、发行溢价、发行人选择 | 无 | 已发布日程来源范围与分类筛选 |
| 9 | CDRC 竞价承销日程 | `CDRCPanel` | 竞价竞争度趋势与发行人选择 | 无 | 竞价公告覆盖与缺失字段边界 |
| 10 | CDRA 固定利率日历 | `CDRAPanel` | 评级分布、迁移矩阵、利差与违约历史视图 | 无 | 固定利率资料状态与证据登记 |
| 11 | CNDS 短期日程 | `CNDSPanel` | 短期事项选择、研究报告与信用预警 | 无 | 短期工具资料范围与时效队列 |
| 12 | CDRV 可变利率日历 | `CDRVPanel` | VRDN/SIFMA/SOFR 比较与风险分析 | 无 | VRDN 公开基准可读性与刷新状态 |
| 13 | DEAL 交易管理 | `DEALPanel` | 原有价格走势、执行质量和交易商得分 | 无 | 执行数据授权闸门与研究留痕 |
| 14 | CACT 公司大事检索 | `CACTPanel` | 公司行动与事项检索交互 | 无 | 事件类别、原始文件状态与更新队列 |
| 15 | MCAL 结构金融日历 | `MCALPanel` | 发行量、承销份额、评级与收益率视图 | 无 | 官方事件资料对齐与期限筛选 |
| 16 | MBIX 最新地方债指数 | `MBIXPanel` | 历史收益、成分、期限、行业利差与因子归因 | 无 | 指数来源许可状态与可读历史边界 |
| 17 | VRDN 彭博7天VRDN | `VRDNPanel` | VRDN/SIFMA/Fed Funds、流动性提供方与重设周期 | 无 | 7 天重设研究与公开基准覆盖 |
| 18 | BMA 地方债掉期指数 | `BMAPanel` | BMA 7 天、BMA/SOFR 期限、税率盈亏平衡与比值时钟 | 无 | 税收等价分析输入与口径卡 |
| 19 | BOOM VRDN库存 | `electronic-trading/BOOMPanel` | 既有委托管理内容与交互 | 无 | 库存数据授权状态与可选择研究范围 |
| 20 | MSRB 统计数据 | `MSRBPanel` | 发行/成交量、交易类型、透明度与市场活跃度 | 无 | MSRB 公开统计口径、延迟与访问边界 |
| 21 | SLGS 国债和市政债利率 | `SLGSPanel` | SLGS 期限、趋势与选择交互 | 无 | 财政部日利率/项目统计的真实终端快照 |

所有 21 个原面板均保留现有状态与事件处理，不将其改写为统一模板。深化组件仅作为同一窗口中原面板后的附加区块，并使用独立的 `municipalResearch` 数据读取与组件状态，避免改变原有数据、控件或渲染路径。
