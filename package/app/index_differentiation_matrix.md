# 指数模块追加式深化矩阵

## 已核验的免费可读基础

在当前运行环境中，FRED 的 SP500、NASDAQCOM、DJIA、VIXCLS、DGS2、DGS10、DGS30、BAMLH0A0HYM2、DEXUSEU 与 DCOILWTICO 均返回实际近期观察。指数研究层只在终端内读取这些公开历史序列；不将其表述为实时、可执行报价、完整指数成分或指数提供商授权数据。

| 原窗口 | 原有工作区职责 | 仅追加的独有研究能力 | 实际数据与边界 |
| --- | --- | --- | --- |
| SECF | 证券与指数检索 | 基准可读性与最近观察目录 | FRED 可读性、日期与历史点数；不伪造成分资料 |
| HELP_INDX | 指数帮助 | 公开资料口径与可用性地图 | 公开序列覆盖说明；无公开序列则明确空状态 |
| WEI | 全球股票指数 | 美国宽基指数共同日期表现路径 | FRED SP500、NASDAQCOM、DJIA；非全球实时行情替代 |
| WEIF | 全球股指期货 | 现金指数与波动环境观察边界 | FRED 宽基指数与 VIX；无免费可核验期货链时保持空状态 |
| WBIX | 全球债券指数 | 利率期限与高收益利差环境视图 | FRED 国债收益率与 ICE BofA OAS；不替代授权债券指数总回报 |
| GMM | 宏观驱动 | 多序列同日宏观市场仪表板 | FRED 利率、信用、汇率、能源与波动率；无因果归因 |
| IN | 指数研究 | 单一基准的区间观察与读数质量 | FRED 可选公开基准；非指数成分与估值数据 |
| INP | 指数输入 | 输入篮子覆盖与公开代码边界检查 | 仅校验用户输入与已读取公开资料，不补全持仓 |
| CIX | 自设指数 | 自设篮子公开价格可读性审计 | 仅对可读标的展示覆盖状态；不生成合成历史 |
| CIXB | 指数篮子 | 权重完整性与集中度检查 | 用户输入权重；不推导未提供的成分数据 |
| AGG | 聚合指数 | 利率期限结构状态与期限差观察 | FRED DGS2/DGS10/DGS30；非债券指数净值替代 |
| FDFD | 因子诊断 | 公开因子环境可用性矩阵 | 可读基准/利率/信用序列；无授权因子收益保持空状态 |
| OTHER_INDEX | 另类与主题指数 | 公开主题、ESG 与另类指数资料覆盖目录 | 无可核验免费历史时显示数据边界 |
| RRG | 相对轮动 | 宽基指数与风险环境的共同日期相对路径 | FRED SP500、NASDAQCOM、DJIA、VIX；不伪造行业轮动轨迹 |
| WT | 跨市场观察 | 股票、利率、美元、能源同窗变化 | FRED 多资产公开序列；不生成交易信号 |
| CIXN | 指数名称与治理 | 名称、代码及阅读路径完整性检查 | 账户输入与公开序列覆盖状态 |
| CIXS | 情景 | 免费宏观环境快照与缺口提示 | FRED 宏观历史，不生成预测情景结果 |
| CIXR | 再平衡 | 最近可读观察变动记录 | 实际序列变化；无权威成分变动则空状态 |
| CIXC | 公司行动 | 可公开核验的调整资料可用性提示 | 无公司行动源时显示边界，不填样例事件 |
| CIXX | 指数计算 | 用户输入约束及观察可复算性状态 | 用户内容与公开历史可读性，不替代原计算器 |
| CIXI | 指数发行 | 指数元数据与公开资料可用性目录 | 无授权提供商参考资料时明确不可用 |
| INDEX_DERIV | 指数衍生品 | 波动率与市场环境观察 | FRED VIX；期权链、Greeks、可执行报价未授权时为空 |
| BBG | 指数浏览 | 指数参考资料覆盖与公开观察目录 | FRED 可读历史与明确授权边界；不冒充授权指数数据库 |

## 统一追加原则

所有能力由独立的保留容器在原页面之后渲染。研究层呈现加载、错误与空状态；核心数据、图表、筛选与资料口径均留在终端页面内，不使用离站跳转作为功能完成方式。
