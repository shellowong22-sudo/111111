# 股票智能驾驶舱与 NCEO：逐项功能矩阵

> 范围锁定：本矩阵只覆盖终端内的**股票智能驾驶舱**与 **NCEO 诺诚增强期权**。不会以新增页面、外跳链接、虚构实时行情或统一工作区替代下列能力。

## 股票智能驾驶舱

| 用户要求 | 当前状态 | 数据边界与下一步 |
| --- | --- | --- |
| 标的基础信息卡 | 部分可用 | 代码、最新公共日频收盘价、日变动与来源可显示；板块、流通市值须获得可验证来源后显示。 |
| K 线与均线／BOLL／支撑压力 | 已可用 | 仅以当前可读取的公开日频 OHLCV 绘制；不把它称为 1／5／15／30／60 分钟 K 线。 |
| 主力／北向／大单资金流 | 授权实时不可用 | 无当前可验证来源；原窗口显示不可用状态而不填充柱状图数字。 |
| 换手率等数据仪表盘 | 已分层呈现 | 日频振幅与量比由 OHLCV 计算；换手率、内外盘、融资余额无来源时明确不可用。 |
| 买卖、止盈、止损价 | 研究替代 | 支撑／压力仅标为日频研究观察，不能作为精确交易指令。 |
| 趋势标签与量能 | 已可用 | 基于公开日频收盘、均线和成交量计算研究标签，保留模型边界。 |
| 分时与盘口 | 授权实时不可用 | 1／5／15／30／60 分钟、逐笔与十档均无来源；点击显示原因，不以日频或模型替代。 |
| 关键价位提醒 | 已可用 | 当前浏览器会话按最新公共日频收盘高亮检查；不伪称持续后台告警。 |
| 历史信号回测 | 授权数据前置 | 未有无前视偏差的验证数据集；不展示胜率、盈亏或最大回撤数字。 |
| 打开 NCEO | 已可用 | 当前标的一键在站内打开 NCEO 模型期权窗口。 |

## NCEO 诺诚增强期权

| 用户要求 | 当前状态 | 数据边界与下一步 |
| --- | --- | --- |
| 正股联动与合约表 | 已可用 | 标的联动和模型 Call／Put 合约表已在原窗口内；不是实盘期权链。 |
| T 型报价 | 已可用 | 使用现有模型 Call／Put Bid／Ask 按同一行权价横排；持续标为模型报价。 |
| 希腊值与 IV | 已可用 | 当前模型链的希腊曲线、合约 IV 轨迹与 30／60／90 天模型期限锥均在原窗口内可见。 |
| 收益、策略及组合腿 | 已可用 | 单腿看涨／看跌及牛市／熊市／跨式／勒式组合均可切换并显示到期损益与模型组合腿。 |
| 研究区间 | 模型替代 | 仅展示模型输入和策略测算区间，不能命名为精确开平仓指令。 |
| 到期日、权利金、杠杆、流动性 | 已可用 | 到期天数、模型权利金、模型杠杆与模型流动性均在原窗口内显示。 |
| 时间衰减 | 已可用 | 由当前模型参数绘制，不假称交易所历史价值。 |
| 保证金与模拟仓位 | 已可用 | 义务仓模型保证金与登录用户范围的模拟账本已可用；不连接券商账户。 |
| 信号历史与阈值提醒 | 已可用 | 已有用户模型动作审计与当前浏览器会话阈值高亮；不伪称真实持续告警或真实成交记录。 |
