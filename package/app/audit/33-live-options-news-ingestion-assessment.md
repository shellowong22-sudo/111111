## 结论与边界

NCEO 当前只能维持模型／模拟报价。NCEO 原窗口现有独立“授权期权买卖报价”状态卡，并通过 `futuresOptions.getLiveQuoteStatus` 实际返回未配置状态；在未接入授权提供方时，市场 Bid、Ask、延迟、来源与观察时间均保持空值。仅在实际接口返回期权合约、买卖两侧报价、来源、延迟状态与时间戳时，才可展示“实时”或“延迟”报价；接口失败、无权限、额度耗尽或字段不足均必须显示真实不可用状态。任何市场数据接入均不会创建、签署或提交券商订单。

管理员新闻功能仅采用来源明确允许的 RSS、公开摘要或官方 API。已核验 `https://rss.sina.com.cn/roll/finance/hot_roll.xml` 在 2026-08-27 返回 HTTP 200 与 XML；该来源已作为管理员归属的 RSS 配置保存。管理员新建来源只需网站名称和网站网址：后台只识别直接 RSS／Atom XML 或公开主页标准的 RSS／Atom alternate 声明，发现失败不会保存来源。单次最多读取 50 个新条目。采集条目仅保存标题、来源、原文 URL、发布时间、取得时间与不超过 1,200 字符的摘要字段；不抓取或保存来源正文。

AI 仅以 `gpt-5-mini` 对保存的标题与有限摘要生成 90–220 字的通俗解读草稿、分类、情绪与可能相关代码。提示词禁止补充输入之外的事实、数字、人物或交易建议；失败时文章标记为失败，系统不会用静态内容替代。草稿必须由管理员批准，批准后仍需单独执行站内发布；所有来源新增、同步、草稿、审核与发布操作写入审计事件。

定时执行采用单一来源、单任务的受认证回调 `/api/scheduled/adminNewsIngestion`。回调以平台认证的 `taskUid` 反查来源而不是信任请求载荷，不会由一个来源任务触发所有来源；孤儿任务以 2xx 跳过。计划创建／更新接口仅允许管理员在成功发布的生产部署中选择 10 分钟、30 分钟、1 小时、6 小时、12 小时或 24 小时频率后调用；当前开发预览不自动建立后台任务，以避免无效调度和未经确认的 AI 处理成本。

## 期权真实报价再次核验

2026-08-27 的官方资料进一步确认：Cboe DataShop 的 Option Quote Intervals 产品可提供美国上市期权的 NBBO Bid／Ask、成交量和可选 IV／Greeks，但需要购买数据产品；其盘中档案相对快照延迟 15 分钟，实时交付需联系销售。Nasdaq Options Data 说明其通过 API 提供实时和历史期权数据，也属于市场数据产品。两者均不能被解读为“无需授权、可由网页爬虫替代”的站内行情接口。

因此，NCEO 的 `getLiveQuoteStatus` 保持未配置状态是正确行为：在用户提供实际订阅的 API 凭据、许可市场、延迟等级和可访问端点前，不能填入真实／延迟 Bid、Ask、期权链、IV 或 Greeks，更不能把模型值改标为实时买卖价。

## 本批配置与处理模式扩展

“稳定队列”与“全量即时”均最多读取 50 条 RSS／Atom 元数据，均保留来源、去重、人工审核和不自动发布的控制。稳定队列每轮最多草稿 10 条；全量即时模式以最多四并发小批尽力处理当前待处理项，并在接近两分钟 HTTP 回调限制前停下。尚未开始的项目保持 `queued`，草稿失败才标记 `failed`，界面呈现已入队、已处理、草稿、失败、待处理的真实计数。

行情 API 仅保存提供方名称、无凭据 HTTPS API 地址与安全环境变量名称三个必要配置；代码、覆盖市场、延迟和字段能力均可留空。密钥值不会写进数据库、浏览器或日志，也不会因为填写网址而假定行情连通。包括 NCEO 真实 Bid／Ask 在内的读取仍须数据商许可、可用凭据与专属字段适配。

## 新浪财经网站导入失败复核（2026-08-27）

被动访问 `https://finance.sina.com.cn/` 未发现可供通用发现器使用的公开 RSS／Atom alternate 声明，因此以主页地址直接创建会正确返回 `SOURCE_PUBLIC_FEED_NOT_DISCOVERED`，并非按钮无响应。随后被动访问既有核验地址 `https://rss.sina.com.cn/roll/finance/hot_roll.xml`，确认其当前可访问并标示为“财经要闻汇总-新浪财经”。后续修复仅将该已核验网站主页受限映射到此公开订阅地址；不扩展为正文抓取、付费墙绕过、反爬绕过或对其他普通网站的猜测性 RSS 路径。

同日对新浪财经公开 RSS 目录 `https://rss.sina.com.cn/finance/` 列出的九个频道执行只读健康探针：财经要闻、焦点新闻、股市及时雨、股票要闻、基金、理财、美股、港股和期货频道均返回可解析 RSS XML，但每个响应当前均为 0 个 `<item>`，频道日期停留在 2018-09-23。因此截图中的“新增 0 条、已处理 0 条”是来源当前为空的真实结果，不能靠重复同步、伪造新闻或抓取该站普通新闻页来改成有数据。RSS 地址选填后，管理员仍可接入其拥有明确允许使用范围且实际含条目的其他公开订阅。
