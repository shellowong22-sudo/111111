# 图表工具栏动作可用性修复

静态盘点确认，`ChartToolbar` 在未收到图表回调或图表节点时仍提供可点击的时间筛选、CSV 与 PDF 入口；点击后仅给出说明性提示，不能完成对应动作。该行为已调整为：未接入时按钮禁用，并以可见标签和 `title` 说明“未接入”；已接入时保留原有回调、浏览器打印或 CSV 下载行为。

| 入口 | 已接入时 | 未接入时 |
|---|---|---|
| 时间筛选 | 调用 `onTimeframeChange` | 禁用，并显示“时间筛选未接入此图表”。 |
| CSV 导出 | 调用 `onExportCSV` | 禁用，并显示“CSV 未接入”。 |
| PDF 导出 | 调用 `onExportPDF` 或基于 `chartId` 打开打印流程 | 禁用，并显示“PDF 未接入”。 |

`server/chartToolbarAvailability.test.ts` 通过 2/2，锁定禁用条件和不可用文案。本记录只覆盖这个共享工具栏组件；其他按钮、菜单和动作入口的全量交互验收仍保持未完成。
