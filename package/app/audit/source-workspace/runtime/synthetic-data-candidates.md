# 随机与模拟数值候选：首轮静态盘点

本记录源于对客户端 `Math.random`、固定伪随机生成器及“模拟”标记的静态搜索。首轮跨文件可达性复核已确认下列六个候选均可由当前终端、电子交易页面或菜单详情挂载；它们不能再被当作未使用遗留文件处理。

| 候选组件 | 静态迹象 | 初步风险 | 下一步 |
| --- | --- | --- | --- |
| `BOOMPanel` | 固定种子生成中标利率、认购倍数、VPIN、投标人行为并每 3 秒刷新 | 高；`ElectronicTrading` 的 BOOM lazy panel 与 `Terminal` 的 BOOM 窗口可挂载 | 已改为来源不可用状态：保留菜单和组件身份，不显示随机委托单、成交率、滑点、稳定性、拍卖或信号数值；刷新控件禁用。 |
| `BTMMEnhancedPanel` | 月度货币与信贷指标混入 `Math.random`，且曲线、政策、回购与利差为固定数值 | 高；`Terminal` 菜单代码 `4` 可挂载 | 已改为来源不可用状态：保留窗口标题和关闭出口，不显示固定/随机利率、利差、情景影响或资金面判断。 |
| `CDSWPanel` | 信用利差历史混入 `Math.random`，CDS 定价、生存概率、信用曲线和 AI 预警为预设数值 | 高；`Terminal` 的 CDSW 窗口可挂载 | 已改为来源不可用状态：保留窗口标题和关闭出口，不显示伪 CDS 报价、定价、信用曲线、隐含 PD 或 AI 预警。 |
| `DESBondPanel` | 债券数据库的条款、评级、估值为预设值，价格历史由随机噪声生成 | 高；`Terminal` 的 DES 窗口可挂载 | 已改为来源不可用状态：保留证券简介标题和关闭出口，不显示预设条款、发行人、评级、估值或随机价格历史。 |
| `DMMVPanel` | 全球曲线、因子、相关性、资金流和策略均为预设值，历史曲线由随机游走生成 | 高；`Terminal` 可挂载 | 已改为来源不可用状态：保留窗口标题和关闭出口，不显示伪曲线、热力图、相关性、资金流或 AI 对冲与因果结论。 |
| `DynamicFunctionPanel` | 多类价格、成交、新闻、宏观、期权和历史序列由固定或随机函数生成 | 高；`Terminal` 与 `MenuItemDetail` 可挂载 | 已在统一实际分派出口关闭所有子工具的伪市场显示，仅显示模块身份、原入口说明和来源不可用边界。 |
| `AISkeleton`、`ChartSkeleton` | 加载骨架的视觉随机布局 | 低；非业务数值 | 不作为市场数据问题处理 |

> 可达性复核发现原“未挂载”判断不成立：这些组件通过终端窗口注册、菜单编码或 lazy import 而非普通页面直连被挂载。它们保留为下一阶段明确修复对象；不能再显示随机值为实时市场、拍卖、曲线或研究事实。

## 本轮 BOOM 边界验证

实际分派路径为 `ElectronicTradingMenu` 的 `BOOM` → `/electronic-trading?panel=BOOM` → `ElectronicTrading` 的 lazy `electronic-trading/BOOMPanel`。该组件的原始随机生成代码仍保留在源码中，以免将其误报为已恢复数据；但是实际 React 返回出口已在无来源时显示不可用状态，且不呈现这些数值。

`server/boomSourceBoundary.test.tsx` 已验证源边界与 jsdom 渲染，结果为 2/2 通过。`server/electronicTradingOriginalContentFingerprint.test.ts` 仍因与本轮无关的 `EquityTradingPanel.tsx` 历史哈希不一致失败；本轮不重写其期望哈希，也不将该失败计为 BOOM 已验证通过。

## 本轮 BTMM 边界验证

`BTMMEnhancedPanel` 的原数据包含没有观察日、来源或读取时间的固定中国国债、政策利率、R007/DR007 与利差数值，且 M2、信贷和社融图表混入随机扰动。实际入口现在仅声明缺少这些可核验序列，并保留关闭窗口和模块身份。与 BOOM 共用的 jsdom 回归现为 3/3 通过。

## 本轮 CDSW 边界验证

`CDSWPanel` 的实际入口包含预设 CDS 报价、保护腿/溢价腿、隐含违约概率、生存概率与信用利差曲线，并对历史利差附加随机扰动；这些值均没有对应的合约条款、来源、观测日或读取时间。该入口现仅保留 CDSW 窗口身份和关闭出口，并清晰显示缺少 CDS 合约、曲线与信用事件记录。BOOM、BTMM 与 CDSW 的联合 jsdom 回归为 4/4 通过。

## DES、DMMV 与 DynamicFunction 边界验证

`DESBondPanel` 的债券静态资料、评级和估值没有可追溯来源，价格历史由随机噪声生成；`DMMVPanel` 的全球曲线、热力图、因子、相关性、资金流和策略结论没有可核验样本，其中历史曲线由随机游走生成；`DynamicFunctionPanel` 按入口分派新闻、期权、宏观、债券、外汇、商品、交易、研究、组合和股票子面板，其中均有固定或随机业务数值。三个入口均保留模块身份，实际渲染统一改为来源不可用状态。六个候选的 jsdom 联合回归为 7/7 通过。

## ETBT 电子交易记录簿边界验证

后续可达性审计发现 `ETBTPanel` 同样通过电子交易菜单进入，并在实际视图中以随机路径生成单品种成交、价格、VWAP、成交量、执行质量和盈亏，还将刷新动作仅显示提示。该入口现保留 ETBT 标题和数据区域身份，但实际渲染改为来源不可用状态，不呈现随机业务数值或伪刷新结果。联合 jsdom 回归扩展为 8/8 通过。

## EMSX 订单与风险边界验证

进一步审计发现 `ElectronicTrading` 的 EMSX 总览和订单录入调用 `trading.getRiskMetrics` 与 `trading.submitOrder`。后端以进程内预置订单、随机风控检查、随机成交价格、随机场所与随机风险/盈亏生成回应，前端会将其显示为实时状态和成交成功。该分片已关闭模拟下单；风险接口返回包含读取时间与限制说明的 `available: false` 状态；EMSX 总览和订单录入保持菜单/窗口身份但显示来源不可用。`tradingSourceBoundary.test.ts` 为 2/2 通过。
