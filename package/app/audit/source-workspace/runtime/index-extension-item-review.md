# 指数专属扩展逐项质量审查

本审查只针对原指数工作区**之后**追加的扩展层。每项均由用户输入或原页面已可读信息驱动，不会抓取外部数据、生成实时指数、替换原曲线/卡片/公告归档或改写账户及官方权重工具。增强审计确认 24 个入口对应 24 个不同专属组件，映射文件为 24/24 行，未发现重复分派、旧统一研究层挂载、旧共享骨架或外部数据调用标记。

| 入口 | 专属任务与结果 | 数据与操作边界 | 代码/交互结论 |
|---|---|---|---|
| INDEX_HOME | 会话观察清单 | 只加入用户输入；不预设指数 | 已测入队 |
| SECF | 分类覆盖格 | 人工勾选不推断分类 | 入口专属 |
| FDFD | 因子披露证据台账 | 不计算因子暴露 | 入口专属 |
| HELP_INDX | 定义溯源完整度 | 仅登记版本、HTTPS、变更 | 入口专属 |

| WBIX | 久期冲击四档网格 | 手动久期/金额；非交易建议 | 已测冲击 |
