# 服务端接口契约静态矩阵

`audit/scripts/audit_interface_contracts.mjs` 对主路由与 `server/routers/` 中的 TypeScript 路由文件进行只读盘点，并将每个过程写入 `audit/runtime/interface-contract-matrix.json`。矩阵包含文件、候选路由名称、过程名称、公开/受保护/管理访问级别、查询或变更操作、输入 schema 是否存在，以及返回块中是否出现数据状态或来源/时间字段。

| 维度 | 盘点结果 |
|---|---:|
| 扫描路由文件 | 109 |
| 过程总数 | 796 |
| `publicProcedure` | 374 |
| `protectedProcedure` | 394 |
| `adminProcedure` | 28 |
| 查询 | 517 |
| 变更 | 279 |
| 含状态字段线索 | 116 |
| 含来源/观测/读取字段线索 | 41 |

状态与来源字段的数量是静态提示，不代表其他过程均存在缺陷：许多过程并不返回外部数据。矩阵用于后续按外部市场、宏观、新闻、申报、拍卖、曲线和研究域筛选需要状态契约的过程，而不将静态扫描冒充运行时接口验收。

> 本阶段未改变接口输入、访问控制或业务返回，仅建立可中断审计清单。逐接口真实调用、鉴权、错误分支和返回契约验收仍保持未完成。
