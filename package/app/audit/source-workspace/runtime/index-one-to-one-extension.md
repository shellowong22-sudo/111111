# 指数区域一对一数据增强实施记录

## 保留边界

`IndexPreservedModule` 现在先渲染带有 `data-preserved-index-workspace="true"` 的原工作区，然后才追加 `IndexDistinctExtension`。原有 `IndexEventWorkspace`、官方公告详情弹窗、账户权重影响核验、官方权重 CSV 导入、账户篮子协作和审计记录仍按照原顺序渲染。原统一 `IndexResearchLayer` 已不再由包装器挂载。

## 一对一功能范围

新扩展覆盖 24 个原入口，完整映射见 `audit/design/index-one-to-one-extension-spec.md`。重点实用功能包括：WEI 的区域相对表现尺、WBIX 的久期敏感度网格、GMM 的宏观传导链条、CIX 的权重闭合检查、CIXB 的权重漂移估算、AGG 的多指数混合收益分解、CIXS 的双腿价差阈值观察、CIXX/CIXI 的日期质量检查及 INDEX_DERIV 的滚动日历。它们只使用人工输入或原页面可读数据，明确不生成实时指数、市场预测、订单、外部新闻或未核验权重影响。

## 截图反馈后的第二轮重构

用户指出截图中原始指数页面之后仍有同类统一工作台外观。对此，`IndexPreservedModule` 已调整为先完整渲染原工作区、`IndexEventWorkspace`、账户协作及官方权重导入，再显示提示和本入口的独立工具；新增扩展不再将公告归档或账户功能置于自身之前。
