# 根终端移动壳层定向修复记录

## 修复范围

移动断点钩子此前在首帧返回桌面状态，导致 `Terminal` 以桌面默认值初始化侧栏。现改为按浏览器初始宽度同步判断；375px 宽度下，侧栏初始保持关闭，主内容可见。为避免底部固定行情条覆盖窄屏末尾内容，终端根容器仅在小于 `md` 的视口预留 `pb-9` 空间；桌面断点恢复为 `pb-0`，不改变原桌面布局。

| 核验项 | 证据 | 结论 |
|---|---|---|
| 初始移动状态 | `server/useMobile.test.tsx`，1/1 通过 | 窄屏首帧为 mobile，不以桌面状态自动展开侧栏。 |
| 375×812 抽样画面 | 根终端两次窄屏截图 | 未见左侧导航抽屉默认覆盖主内容；主内容可见。 |
| 底部固定行情条 | 第二次窄屏截图及 `Terminal.tsx` 的 `pb-9 md:pb-0` | 终端内容区在移动端结束于行情条上方。 |

该记录只证明根终端壳层的侧栏与底部遮挡问题已修复，不构成各业务页面、表格和弹窗的全量移动验收；该更广泛验收仍保留在总体待办中。
