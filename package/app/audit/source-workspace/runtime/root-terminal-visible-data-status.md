# 根终端可见数据状态契约分片

本分片只审计根终端中实际可见的**官方事实阅读**和**全局数据库市场快照**。它不将项目恢复快照表述为实时行情，也不将原 AI 市场简报表述为可验证事实。

| 可见区域 | 实际数据路径 | 已展示的状态边界 | 本轮验证 |
| --- | --- | --- | --- |
| 官方事实阅读 | `newsResearch.getOfficialFeed` | 仅列出本次读取的 SEC/美联储条目；显示机构、来源标签、发布时间、来源标识和定位 URL；读取失败或空结果时不以新闻或行情替代 | `newsTopOfficialFacts.test.ts` 6/6 通过 |
| 全局行情条 | `market.getAll` → 项目数据库导入快照 | 显示“数据库导入快照”、最新观测与本次读取时间；初始读取和“数据库快照不可用”分开；不自动请求外部行情 | `globalHeaderObservation.test.ts` 1/1 通过 |
| 原 AI 市场简报 | `marketBrief` 的历史保留区 | 仅在折叠区保留；明确标示其情绪、影响、板块和建议为非事实，不作为实时价格或交易依据 | 静态结构由 `MarketBriefPanel.tsx` 的历史边界标识覆盖 |

> 本分片的局限是：它并不构成其他外部数据模块的全量契约验收；完整清单仍由总体待办追踪。
