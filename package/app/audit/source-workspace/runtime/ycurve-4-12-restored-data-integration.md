# 收益曲线 4–12：恢复数据接入与热力图填充

九个工作流现共享一个**只读、可选择观测日的官方历史曲线快照面板**，来源于项目数据库内已恢复的美国财政部 Daily Treasury Par Yield Curve 归档资产。该面板显示来源 URL、观测日、读取时间、2Y/5Y/10Y/30Y 节点与限制说明；它不是实时或可执行报价。

VCUB 热力图不再使用空白格：每个格点显示当前选择观测中的期限与实际导入收益率；点击格点会更新选中期限、观测值和本地方差缩放解释。CRV 新增“载入恢复快照节点”，将所选官方观测复制为可编辑的本地工作版本；其他入口均可在其独立流程中使用同一可追溯观察基线。

外部实时市场、宏观、新闻、订单簿和波动率曲面未接入时，界面明确标注而不补造数据。定向回归为 **7/7 通过**，覆盖恢复数据查询、来源状态、观测日、期限收益率、VCUB 热力格点及原有九项差异化工作流。
