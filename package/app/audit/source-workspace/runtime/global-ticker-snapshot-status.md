# 全局行情条快照状态修复

全局行情条仅消费项目数据库已导入的 `market_data` 快照，不会在页面加载时发起外部行情请求，也不会以固定数值或随机值补足空状态。本次修复将原先仅在悬浮提示中可见的部分元数据提升为可见状态栏。

| 状态 | 可见信息 | 数据行为 |
|---|---|---|
| 读取中 | “正在读取已导入数据库快照；不发起外部行情请求” | 不展示猜测值。 |
| 已有快照 | 来源、最新观测时间、本次读取时间 | 展示已恢复的导入快照。 |
| 无快照 | 无快照原因与本次读取时间 | 保持真实空状态。 |

`server/globalTickerSnapshotStatus.test.ts` 通过 2/2，锁定可见来源、观测时间、读取时间和无快照原因。根终端桌面抽样显示底部状态栏已显示“数据库导入快照 · 来源：项目数据库导入 · 最新观测 · 本次读取”，右侧卡片继续标记“项目数据库导入快照”。该核验不代表所有外部数据模块的完整状态验收；全项目要求仍保留在总体待办中。
