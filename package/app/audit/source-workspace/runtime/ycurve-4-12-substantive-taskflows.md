# 收益曲线 4–12 实质性任务流

本轮将可视化层下的每项都连接到不同的本地数据任务。所有载入内容由用户粘贴或编辑；外部市场曲线未接入时不读取、不猜测、不伪造数据。

| 代码 | 本地数据任务 | 运行产出 | 工作状态 |
| --- | --- | --- | --- |
| GCT | 观察备注与节点 | 区间、标签、复核清单 | 保存复核清单 |
| FWCV | 期限节点 | 端点变化、斜率、期限贡献 | 保存归因结果 |
| FWCM | 矩阵行 | 空值、反向变化、锁定检查 | 锁定校验版本 |
| ICUR | 待插值期限 | 端点内/外与人工确认节点 | 保存审计结论 |
| BNCH | 候选基准 | 利差排序与阈值穿透 | 记录审阅决定 |
| ICVS | 现金/掉期腿 | 金额差、方向、待确认项 | 保存核对票据 |
| GC3D | 冲击集合 | 最小/基准/最大情景范围 | 保存情景集 |
| CRV | 版本节点 | 新增、删除、变动与斜率差 | 提交工作版本 |
| VCUB | 波动率格点 | 覆盖、空白区域、补充组合 | 保存覆盖报告 |

定向回归为 **6/6 通过**，覆盖九个专属任务动作、九种图形、数据边界及 GCT/VCUB 的真实状态变化。
