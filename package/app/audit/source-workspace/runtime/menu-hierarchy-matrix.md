# 菜单层级与间接导航静态矩阵

菜单层级审计以 ZIP 基线的 `audit/inventory/menu-components.tsv` 为输入，对 26 个非 UI 菜单组件进行只读提取。每个组件的标题候选、编号条目、功能编码、功能名称、可见条件线索、是否使用通用菜单处理器和是否调用位置导航均存入 `audit/runtime/menu-hierarchy-matrix.json`。

| 维度 | 当前结果 |
|---|---:|
| 原始菜单组件 | 26/26 已存在 |
| 含编号功能条目的菜单 | 10 |
| 已提取编号条目 | 282 |
| 使用通用编码处理器 | 17 |
| 直接使用位置导航 | 13 |
| 菜单组件内可见条件线索 | 0 |

菜单组件内未发现 `user`、`role`、`admin`、`isAdmin`、`isAuthenticated` 或 `useAuth` 条件；权限可见性仍由终端命令栏与路由守卫承担，并已在路由矩阵中单独记录。编码条目的导航目标由 `menuItemHandler` 解析为配置路径或 `/menu-item/:itemId` 回退；对应的 526 个直接/编码目标均已由路由菜单矩阵静态核验为可达。

> 该矩阵证明菜单定义、编号条目、编码与处理方式仍在源中，不代表每项的可见性、弹层、点击、跳转、加载态和错误态已在浏览器中逐一验收。
