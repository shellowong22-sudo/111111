# 交易委托簿 23 个专属扩展：阶段性实施记录

原 `OrderManagement` 页面仍完整包裹在 `data-preserved-order-management-workspace=true` 中。页面原有的订单管理、原导入/阈值/归档功能及其既有不可用边界没有被改写；后置的 `OrderManagementResearchLayer` 已停止挂载。

新增层由当前 `panel` 参数选择 23 个不同的专属工具。它们涵盖字段完整性、双边报价、经纪商分配、覆盖层级、交接时钟、日终清单、冲击格、证据台账、容差、依赖链、术语卡、异常路径、结算归因、篮子闭合、成分变动、创建单位、权限矩阵、阈值观察、版本簿、发布门禁、容量条、字段交接链和事件轨道。每项只处理会话中的手动输入，不会提交委托、访问场所、推测报价或覆盖原数据。

本记录仅覆盖交易委托簿；电子交易、STP 和交易账簿的同类统一层仍在后续专项改造范围内。
