# 外部数据状态契约初步盘点

本盘点尚未形成所有外部数据模块的完成结论。服务端检索发现 42 个路由文件含有外部数据调用或来源/状态字段，其中公开数据路由通常使用 `source`、`observationDate`、`fetchedAt`、`status` 或 `limitation` 表达可用性与限制。

## 明确待处理项

`server/routers/derivatives.ts` 的替代数据信号和行业概览存在固定数值、信号、概率或置信度，且未附可验证来源、观测时间、读取时间与不可用原因。例如，替代数据信号列出“港口吞吐量环比-3.2%”及固定置信度，行业概览列出固定表现、配置判断和 `altDataScore`。这些内容不能被展示为真实外部市场、传感器、新闻或研究数据。

> 该项仅记录风险与恢复边界。因路由属于 ZIP 复制的原业务区域，本轮未直接删除或改写；后续必须以独立不可用状态或可验证来源替换其对外数据语义，并以定向契约测试证明不再把固定样例作为实时或已观测事实。

## 已实施的定向替换

为消除上述固定事实，本次仅保留衍生品原有页面和卡片结构，将 `generateAltDataSignals`、`buildCausalChain` 与 BICO 行业概览的固定数据返回改为零条可验证观测。BICO 原有感知层、推理层、行业热力图、评分雷达、研究矩阵和风险矩阵都保留在原位置，但在无授权来源时明确显示不可用，而不显示固定评分、概率、表现、风险分组或“实时”标记。

| 核验项 | 结果 |
|---|---|
| 固定外部事实 | 已移除固定替代信号、行业表现/评分/配置、预设概率与时滞链。 |
| 原页面结构 | BICO 顶部状态卡、两张图表卡与研究矩阵仍存在；仅在原位置呈现不可用说明。 |
| 真实状态文案 | 明确显示授权来源未接入、来源/观测未提供、读取时间边界和“不以固定内容替代”。 |
| 定向测试 | `server/derivativesExternalDataStatus.test.ts` 3/3 通过。 |
| 桌面抽样 | `/bico` 可渲染，显示 0 个可验证信号、0 条可验证链及行业表现/评分/矩阵不可用。 |

该修复不涵盖衍生品路由中的全部其他静态业务示例、LLM 输出或所有外部模块；全量状态契约清单仍保持未完成。

全局导入快照行情条已单独完成来源、观测时间、读取时间和无快照原因展示，见 `audit/runtime/global-ticker-snapshot-status.md`；该完成范围不覆盖本盘点中的衍生品路由。
