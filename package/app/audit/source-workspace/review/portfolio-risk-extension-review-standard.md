# 投资组合与风险扩展逐项审查标准

每个原 tab 必须同时满足以下六项。任何一项不成立，即不得称为“完善”。

| 维度 | 通过标准 | 不通过示例 |
| --- | --- | --- |
| 原功能隔离 | 原 ZIP 工作区仍先渲染，扩展只在其后追加。 | 替换原路由、移除原面板、覆写原文案。 |
| 独立任务 | 每个 tab 有与原区域对应的不同工作目标。 | 仅把同一“研究导航/阅读/摘录”换标题。 |
| 可操作输入 | 输入、选择、勾选、滑杆或真实账户数据具有明确来源。 | 静态数字、不可编辑控件或虚构数据。 |
| 可验证结果 | 输入改变会产生计算、状态、表格、图形、导出或受控服务端结果。 | 点击无反应、只显示成功提示或固定样例。 |
| 诚实边界 | 未接入网络、订单、通知、实时估值或权限数据时明确说明。 | 把会话计算说成实时服务或伪装为外部连接。 |
| 参考价值 | 输出帮助用户检查权重、偏离、风险、约束、证据、时点或数据准备度。 | 没有决策/复核用途的空泛文字卡片。 |

审查采用三层证据：源码/映射结构审计、组件交互测试、桌面与移动加载检查。页面展示并不替代真实交互测试；会话内结果也不被描述为账户持久数据或投资建议。
