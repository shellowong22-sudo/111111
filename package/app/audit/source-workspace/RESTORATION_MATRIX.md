## 原主导航层级

原 `ModuleNavigation.tsx` 定义八个一级模块：**市场**、**权益与衍生品**、**通讯与社区**、**新闻与研究**、**经济分析**、**专业应用**、**平台工具**、**个性化工作台**以及 **帮助与关于**。一级模块的子项均由同一组件装配到原始独立菜单组件，或交由原有模块选择逻辑处理；该装配方式未改写。

| 一级模块 | 原始子菜单或入口 |
| --- | --- |
| 市场 | 主权债、信用债、抵押债、货币市场、地方债、优先股。 |
| 权益与衍生品 | 股市、大宗商品、指数、外汇、衍生品。 |
| 通讯与社区 | 通讯与社区菜单。 |
| 新闻与研究 | 新闻与研究报告菜单。 |
| 经济分析 | 经济数据及分析菜单。 |
| 专业应用 | 投资组合管理与风险、定价与风险分析、交易委托简、电子交易界面、STP、交易账簿管理、行业分组分析。 |
| 平台工具 | 灵活屏、数据导出、BQuant、移动版、设定。 |
| 个性化工作台 | 我的看板。 |
| 帮助与关于 | 快捷键、文档、关于。 |

> “市场状态 Open”和“Connected”是基准主导航的原始静态文本，不能据此推断外部数据源或交易通道实际可用。运行时验收会将此类展示文本与真实数据状态、读取时间及不可用原因分开记录。

## 已知基准随附限制

基准内的 `RECOVERY_STATUS.md` 已记载全量 TypeScript、完整客户端依赖图和 Vite 构建在原环境遭遇 Node 堆内存限制，同时保留 `13` 个基准外内容或已确认研究层互斥断言导致的失败。该记录只是原始证据而非本次验收结论；本次将在不修改基准的条件下复跑并保存新的原始日志。
