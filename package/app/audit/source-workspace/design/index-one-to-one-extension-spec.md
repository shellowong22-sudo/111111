# 指数区域一对一数据增强扩展规格

所有条目只在原指数页面、数据卡、曲线和已实现的数据工具之后追加；不替换、不模拟也不复制原数据面板。用户输入的值只用于会话内计算，预填内容须标为示例。

| 原入口 | 独立扩展 | 输入 | 结果与交互 | 明确边界 |
| --- | --- | --- | --- | --- |
| INDEX_HOME | 指数观察清单 | 名称、观察点、备注 | 优先级队列 | 不生成实时指数数据 |
| SECF | 分类覆盖矩阵 | 分类、覆盖状态 | 缺口计数与矩阵 | 不推断分类 |
| HELP_INDX | 定义溯源卡 | 口径、来源、版本 | 版本差异清单 | 不生成授权资料 |
| WEI | 区域相对表现尺 | 两个手动收益 | 相对差与条形尺 | 不替代原全球指数表 |
| WEIF | 筛选规则试算 | 规则名、命中数、总数 | 命中率仪表 | 不筛选真实成分 |
| WBIX | 久期敏感度网格 | 久期、收益率变动、金额 | 价格近似冲击矩阵 | 不替代原债券指数数据 |
| GMM | 宏观传导笔记 | 驱动、通道、置信度 | 传导链条 | 不预测市场 |
| IN | 标识符格式核对 | 指数代码、市场、币种 | 格式状态 | 不查询外部主数据 |
| INP | 快照字段核对 | 列名、日期、来源 | 数据准备度 | 不创建市场快照 |
| CIX | 权重闭合检查 | 成分、权重 | 权重合计与缺口 | 不保存自设指数 |
| CIXB | 权重漂移估算 | 目标/当前权重 | 漂移条与会话 CSV | 不覆盖账户篮子 |
| AGG | 多指数混合器 | 指数名、比例、收益 | 混合收益分解 | 不生成指数报价 |
| FDFD | 因子披露检查 | 因子、披露状态 | 缺口表 | 不计算因子暴露 |
| OTHER_INDEX | 指数类型分流器 | 名称、规则、用途 | 分类建议草案 | 不授权或发布指数 |
| RRG | 象限迁移登记 | 板块、起止象限 | 迁移路径图 | 不重算原 RRG 数据 |
| WT | 权重方法对照 | 方法、更新日、复核人 | 方法日历 | 不改写现有权重 |
| CIXN | 成分算术核验 | 数值表达式 | 安全求值与步骤 | 不替代原计算器 |
| CIXS | 价差阈值观察 | 两腿值、阈值 | 价差状态灯 | 不生成报价 |
| CIXR | 比率变动日志 | 分子、分母、基准 | 比率与变动 | 不保存原比率 |
| CIXC | 单位换算复核 | 值、来源单位、目标单位 | 换算结果与单位标签 | 不替代原换算器 |
| CIXX | 日期覆盖分析 | CSV 文本 | 重复/缺失日期统计 | 不导入原序列 |
| CIXI | 序列缺口标注 | 日期/值文本 | 缺口与连续段 | 不保存原时间序列 |
| INDEX_DERIV | 合约滚动日历 | 到期日、持有日 | 剩余天数与日历状态 | 不创建衍生品订单 |
| BBG | 字段契约预检 | 字段、来源、状态 | 字段就绪表 | 不调用 Bloomberg 或外部接口 |
