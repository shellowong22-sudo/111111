# 投资组合与风险：一对一独立扩展规格

## 隔离边界

原始工作区保留在 `data-preserved-portfolio-workspace` 容器中，不更改其页面、路由、文案或交互。原统一注入层同时渲染“24 模块研究导航”“账户私有情景、限额与研究档案”和“多快照趋势”，造成各原区域看到同一套目录与阅读工作台。本规格将该注入层替换为按 `moduleId` 分派的单一独立扩展。

| 原区域 | 独立扩展 | 真实输入与交互 | 可视化/结果 | 不可用边界 |
| --- | --- | --- | --- | --- |
| SYS | 终端恢复完整性核对 | 选择核对项、记录本次确认 | 完整性矩阵与会话确认记录 | 不声称服务可用性。 |
| PRTU | 权重再平衡草案 | 输入名称、权重与目标权重 | 偏离条形图与再平衡差额 | 仅会话草案，不生成订单。 |
| BBU | 基准偏离分解 | 输入组合/基准权重 | 主动权重瀑布表 | 不代替基准授权或证券数据。 |
| PORT | 集中度透视 | 输入持仓权重 | HHI、Top-N 与集中度环图 | 不生成风险评级。 |
| PORT IP | 日内净值变动台账 | 输入起止净值与现金流 | 净变动、收益率和瀑布 | 不接入时不伪造日内估值。 |
| PDSP | 字段展示编排器 | 勾选字段与密度 | 实时预览表格 | 不保存为原页面配置。 |
| PORT TE | 主动收益配对检验 | 粘贴组合/基准收益序列 | 配对覆盖、主动收益与离散度 | 长度或日期不齐时拒绝计算。 |
| PORT VR | 历史分位风险估算 | 粘贴单序列收益与置信度 | 分位数、尾部观测和直方图 | 仅输入样本统计，非实时 VaR。 |
| PORT SA | 冲击损益网格 | 输入敞口、敏感度和冲击区间 | 情景矩阵与损益色阶 | 不给出交易建议。 |
| PORT HD | 持仓集中度分桶 | 输入持仓与权重 | 权重分桶和 Top 持仓图 | 未输入持仓保持空。 |
| PORT CH | 加权特征计算器 | 输入权重与期限/收益率等特征 | 加权均值与完整性提示 | 不补全缺失字段。 |
| PORT HP | 净值回撤轨迹 | 粘贴净值点 | 回撤曲线、峰谷和最大回撤 | 不拼接不同组合历史。 |
| PORT PA | 归因桥接 | 输入期初、交易、市场、费用 | 贡献桥与残差校验 | 残差不为零明确提示。 |
| PORT TS | 交易影响试算 | 输入交易金额、组合值、成本 | 换手率、现金影响与成本 | 不创建订单或报价。 |
| PORT OP | 约束可行性诊断 | 输入目标/最小/最大权重 | 约束缺口与可行性状态 | 不产出优化权重。 |
| NL | 证券新闻证据队列 | 输入链接标题与发布日期 | 来源卡片、时效标签和待核验队列 | 不抓取或生成新闻内容。 |
| EVTS | 事件依赖日历 | 输入日期、事件与责任人 | 倒计时、周视图和依赖状态 | 不把事件当作市场预测。 |
| PREP | 报告完备性清单 | 勾选事实、图表和审阅项 | 可导出 Markdown 摘要 | 不生成投资结论。 |
| MIFI | 合规证据缺口表 | 填写政策/审批证据状态 | 缺口矩阵 | 明确不构成合规意见。 |
| ALRT | 本地阈值观察器 | 配置指标、阈值和实际读数 | 状态灯、消费仪表与历史记录 | 仅会话内观察，不发通知。 |
| DRPT | 备选方案比较板 | 输入方案、证据、限制与分数 | 比较矩阵与导出 CSV | 不给出最终投资决策。 |
| AUDT | 本会话操作留痕 | 自动记录扩展内操作 | 时间线与 CSV 导出 | 不混同原审计日志。 |
| INTG | 连接配置预检 | 输入端点名与 URL | URL 语法、HTTPS 与字段需求检查 | 不发出网络请求或伪造连通性。 |
| BOND RISK | 债券情景档案 | 复用已有账户私有快照、限额与情景 | 久期、凸性、DV01、损益与导出 | 仅在真实快照存在时启用。 |

所有会话内计算都标明输入来源和不持久化边界；任何真正保存、导出或调用服务端的动作均使用已实现路径。没有实现的网络连接、订单、通知或外部数据操作以不可用状态明确呈现。
