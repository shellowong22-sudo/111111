# 指数区域原功能保留边界

用户明确确认指数区域中现有的数据、曲线、期限卡片、官方成分公告弹窗、成分变更归档、账户权重核验和官方权重表导入功能具有参考价值，必须完整保留。扩展层只能挂载在原工作区之后，并且只替换重复的 `IndexResearchLayer`。

| 原功能范围 | 保留规则 |
| --- | --- |
| `IndexHub` 根页面 WEI、WBIX、RRG、CIX、GMM | 保留既有列表、筛选、指标卡、图表、轮动与自设指数交互；不将其替换为扩展卡片。 |
| 23 个深链面板 | 保留 `PANEL_MAP` 的现有路由和原面板；扩展仅从 `IndexPreservedModule` 追加。 |
| `IndexEventWorkspace` | 保留官方公告归档、详情弹窗、成分新增/移除、来源/读取时间、账户级权重影响核验。 |
| `IndexOfficialWeightImportPanel` | 保留登录后的官方 CSV 校验、来源 URL、日期、权重合计、导入历史和服务端写入。 |
| `IndexBasketCollaborationPanel` | 保留账户篮子、协作、权限与审计记录功能。 |

后续一对一扩展不得生成实时价格、自动交易、推测成分、伪权重影响、伪新闻或替代原数据。原数据为空或权重未导入时，应保留既有真实空状态。
