# FXDS 外汇数据检索交互修复

用户报告 FXDS「外汇数据检索」面板中的刷新、导出和货币对列表入口无响应。修复保留既有深色表格布局和非实时资料边界，不将归档快照描述为实时、可执行报价或交易权限。

| 入口 | 修复后的站内行为 |
| --- | --- |
| 刷新图标 | 重新读取当前面板保存的非实时快照，更新可见读取时间与成功状态。 |
| 导出图标 | 仅将当前筛选结果生成浏览器本地 CSV 下载，不跳转至外部网站。 |
| 搜索与品类按钮 | 搜索、即期筛选、远期/期权/掉期真实空态以及排序均实际影响当前列表。 |
| 货币对行 | 打开站内快照详情对话框，明确说明资料不代表可执行报价或订单簿。 |
| 星标按钮 | 在当前面板中加入或移除观察状态，并显示可观察的计数与图标状态。 |

验证包括 `server/fxdsPanelInteraction.test.tsx` 的 2/2 回归通过、`/terminal?open=FXDS&module=forex` 的深链可视化确认，以及修复后的生产构建通过。
