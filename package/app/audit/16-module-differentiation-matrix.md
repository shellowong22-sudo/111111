# 模块与子功能差异化升级审计矩阵

本矩阵保持现有终端壳层、左侧导航、模块位置和冻结页面入口不变。每一行定义**不可与其他行复用**的领域对象、指标、筛选、详情、图表和工作流。被冻结保留的现有页面将先经逐入口审计；可以独立补强的功能置于其后的扩展边界，无法验证的入口标注“建设中”，不得伪装为可用功能。

| 模块 / 子功能族 | 当前问题或审计重点 | 独立功能设计 | 专属数据映射 | 验收动作 |
|---|---|---|---|---|
| 主权债 | 菜单深、曲线/拍卖/国家研究入口需逐项核验 | 期限结构、拍卖日历与财政融资链路 | `curve_id`、期限点、拍卖品种、投标倍数、结算日 | 期限切换驱动曲线与拍卖明细联动；缺失点不插值 |
| 信用债 | OAS 与授权评级/TRACE 数据边界须清楚 | 指数级利差、评级迁移、发行人披露核验 | 指数 OAS、评级桶、发行人、披露事件 | 利差窗口/评级桶/发行人详情各自联动；无授权则空态 |
| 抵押债 | 池、提前还款和利差不能套用信用债页 | 现金流分层、CPR/PSA、机构池比较 | 池号、WAC、WALA、CPR、机构担保 | 选择池后切换现金流与提前还款情景 |
| 货币市场 | 融资利率和短端工具需独立于收益率曲线 | 隔夜/期限资金、回购抵押品和基差 | SOFR、OIS、回购期限、抵押品类别 | 期限阶梯、抵押品筛选与资金缺口联动 |
| 地方债 | 税务、发行人和债券保险维度不可复用主权债 | 税收等价收益率、发行人信用、到期梯 | 发行人、州、税收类别、保险、到期 | 税务假设改变收益率比较，不展示主权债字段 |
| 优先股 | 股息与赎回特征不可套用普通股票 | 固定/浮动股息、赎回日、重设利差 | 股息率、首次赎回、基准利率、重设利差 | 选择证券后展示股息路径与赎回敏感性 |
| 股市 | 现有全球目录已恢复；行情与基本面须分层 | 全球代码目录、公司事件、财务期与观察 | 代码、国家、交易所、来源工作表、财报期 | 国家/名称/分页筛选与来源行号验证；行情不可用则明确 |
| 大宗商品 | 不得复用股票报价/新闻结构 | 现货-期限结构、库存、产地和运费冲击 | 合约月、库存、产地、基差、运费 | 切换品种显示期限曲线和库存事件，而非公司详情 |
| 指数 | 成分、权重与再平衡独立于股市目录 | 成分股覆盖、权重归因、再平衡追踪 | 指数、成分、权重、生效日、再平衡事件 | 选择指数后变更权重贡献和成分生效时间 |
| 外汇（优先） | 现有外汇菜单含多个静态/待核验入口 | 货币对、期限、利差、央行事件、跨币种基差 | 货币对、bid/ask/mid、周期 OHLC、政策利率、经济事件 | 货币对选择联动走势、热力/排行、利差与事件；详见后续专项审计 |
| 衍生品 | 未授权波动率/成交数据不得伪造 | 波动率曲面、期限、希腊值、保证金情景 | 标的、行权价、到期、隐波、delta/vega | 更改行权价/到期仅更新期权曲面和希腊值 |
| 通讯与社区 | 讨论、任务和引用不等同新闻 | 主题线程、研究协作、来源引用状态 | 话题、作者、权限、引用、任务状态 | 发布/回复须真实保存或标记建设中，不跳转第三方 |
| 新闻与研究 | 新闻正文、来源与检索必须独立于行情模块 | 来源归档、实体提取、时间线和阅读队列 | 标题、来源、发布日期、实体、标签 | 搜索/标签/时间线联动，来源点击保持终端内 |
| 经济分析 | 官方观测与经济日历不能套用研究文章页 | 指标发布、频率、预测差、央行日历 | 指标、频率、实际/预期、发布时点、国家 | 指标筛选驱动日历与历史观察，缺失显示空态 |
| 投资组合管理与风险 | 持仓、暴露和情景不可复用交易账簿 | 组合暴露、因子分解、限额、情景压力 | 组合、持仓、因子、限额、情景 | 组合选择驱动暴露/压力；无账户数据不制造持仓 |
| 定价与风险分析 | 估值方法和曲线输入独立于组合页 | 现金流、折现曲线、敏感度、情景 | 工具、现金流、曲线节点、DV01、情景 | 输入变动改变价格/敏感度，不产生交易指令 |
| 交易委托简 | 工作流为委托生命周期而非电子交易 | 委托、审批、路由、状态和异常 | 委托号、状态、审批人、路由、原因 | 创建/审批需真实持久化；否则建设中且不可伪提交 |
| 电子交易 | 经纪商/账户来源未接入 | 连通性状态、可用性边界和模拟隔离 | 会话、经纪商、账户、订单状态 | 未接入时明确不可用，不显示伪订单或成交 |
| STP | 对账和异常处理独立于委托簿 | 消息映射、字段校验、异常队列、修复轨迹 | 消息、字段、规则、异常、处理人 | 异常筛选/修复需要可审计记录；否则建设中 |
| 交易账簿管理 | 账簿、损益和会计事件不可复用组合页 | 账簿归属、日内损益、已实现/未实现、过账 | 账簿、交易、成本、损益、过账状态 | 账簿选择联动损益和过账详情；无账簿数据为空态 |
| 行业分组分析 | 同业分类和经营指标不可复用新闻研究 | 行业分类、同业组、经营指标、比较区间 | 行业、公司、指标、期间、分位 | 行业/指标切换驱动横截面比较与离群详情 |
| 平台工具 / 工作台 / 帮助 | 不能以金融卡片替代工具功能 | 布局管理、导出、快捷键、文档与状态 | 工作台布局、导出任务、快捷键、文档章节 | 保存/导出/快捷键有可复现效果；不可用显示建设中 |

> **零复用判定。** 两个模块即使同用终端配色与表格组件，也不得共享领域对象、核心指标组合、筛选维度、详情语义、图表含义或操作路径。共享的只能是基础 UI 原子组件、认证、错误边界和来源边界；不能共享业务页面模板。

## 外汇优先设计约束

外汇不采用股票的证券目录或公司详情，不采用债券的期限收益率与发行人信用流程，不采用商品的库存/产地链路。其最小独立闭环为：**货币对选择 → 报价/点差与周期走势 → 期限和政策利差 → 货币强弱热力或排名 → 央行/经济事件时间线 → 货币对详情与来源状态**。数据源无可验证时，显示“建设中”或明确“模拟数据”，不得显示未标注的实时汇率、K 线或预测。
