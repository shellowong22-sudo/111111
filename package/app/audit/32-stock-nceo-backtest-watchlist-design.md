# 股票／NCEO 历史研究回测与观察池设计

## 目标与限定范围

本批仅扩展终端内的**股票智能驾驶舱**及其 NCEO 关联能力。自选池、网格和历史研究均按登录用户隔离；不保存券商账户、真实委托、真实成交或持仓，也不建立自动下单、持续告警或外部跳转。

## 数据分类与统计边界

| 能力 | 数据基础 | 当前实现边界 |
| --- | --- | --- |
| 股票研究回测 | 标的与 `SPY` 分别由 `market.getHistory` 实际返回的公共日频完整 OHLCV | 每个信号日只使用当日及此前数据计算；可选第 **1／3／5 个后续交易日**收盘作为结局，构造至少一个交易日的信息截止间隔。 |
| 信号定义 | 日频收盘、MA5、MA10 和 20 日内日频支撑／压力观察 | 仅为可复算的研究筛选，不显示“建议买入”“建议卖出”“止盈”“止损”或保证收益。样本不足时不计算结果。 |
| 回测统计 | 同时具有标的与 SPY 信号日／结局日的公共日频交集 | 显示净策略样本数、正收益观察数、正收益比例、平均净研究收益、最大不利观察、最大回撤、策略／SPY 累计表现与净值曲线；不将正收益比例称为未来胜率。 |
| NCEO 历史表现 | 当前模型期权链、用户模型动作审计 | 现有模型链不含可验证的历史期权报价、逐日合约存续和公司行动调整，因此**不计算或展示期权策略历史胜率、盈亏或最大回撤**。只显示用户的模型动作记录和来源边界。 |
| 自选池与屏风 | 用户主动选择的股票代码及 NCEO 模型合约描述 | 支持默认研究观察池与多个用户命名池；一项条目只保存类别、代码、显示名、可选模型方向、池内显示顺序与创建时间；不保存真实账户或交易数据。 |
| 布局 | 用户主动选择的列数、可见列和网格配置 | 默认池保留既有用户布局；命名池按用户／观察池分别保存布局。恢复时重新读取当前数据，不将过去模型价格或日频价格冒充为最新值。 |

## 无前视偏差规则

研究引擎从第 10 个可用日频观察开始判定，每一个研究信号在日期 `t` 只使用 `t` 或更早的 OHLCV 计算。用户选择持有期 `N ∈ {1,3,5}` 后，结局只读取第 `t+N` 个后续交易日的收盘价；若无该后续交易日，则不纳入统计。策略毛收益为偏强时 `(P[t+N]/P[t]-1)`、偏弱时其相反数；可见成本假设为每边 `c` bp，净收益统一为毛收益减 `2c/100` 个百分点。该规则避免以未来收盘价反向选择信号。

基准比较只保留信号日与结局日都能在 `SPY` 公共日频中找到的样本。SPY 净收益为 `(SPY[t+N]/SPY[t]-1) - 2c/100`；若任一日期缺失，整条候选信号被剔除并在界面披露剔除数，而非插值或填补。净值曲线从 `100` 起按每条时间顺序的净收益复利，最大回撤以策略净值历史峰值为基准。若标的、SPY、日期交集或 MA 样本不足，界面显示空状态和原因，而不输出统计数字。

## 数据持久化最小模型

新增 `stock_nceo_watchlist_collections`、`stock_nceo_watchlist_collection_layouts`，并给既有 `stock_nceo_watchlist_items` 增加可空 `collection_id`。所有表都以 `user_id` 作为强制读取和写入条件。已有条目保持 `collection_id = NULL`，即默认研究观察池；删除命名池时只将其条目回退到默认池，绝不静默删除条目。观察池条目只允许 `stock` 与 `nceo_model` 两种类别；布局不保存行情快照。回测记录在本批只作为页面的可复算结果和本地导出，不持久化为“业绩”或“交易记录”。

> 页面所有与策略、模型或合约相关的字段均应继续显示“研究／模型／模拟、非实时、不可执行”的边界。公共日频价格也不是盘口、逐笔成交、可执行报价或个性化投资建议。
