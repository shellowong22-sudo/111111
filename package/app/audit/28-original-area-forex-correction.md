# 外汇原功能区整改说明

本记录回应用户对“21 个功能升级”范围的澄清：升级的对象是各个既有外汇代码入口的**原功能区**，而不是第 21 张截图，也不应以 FIRS、GP、新闻资料或通用研究层替代其他功能。

| 用户澄清 | 已执行的纠正 | 保留的边界 |
|---|---|---|
| 恢复“彭博率先报道”，GP 继续删除 | 后续明确要求已撤销 FIRS 的移除：`FIRS` 现恢复至外汇菜单与终端映射，保留其原新闻筛选、列表和行内详情；`GP` 继续保持移除 | 不重新挂载与 FIRS 无关的统一研究层；不删除其他市场分类可能使用的共享组件 |
| 新闻在原区内按条展开数据图 | `FIRS`、`FXIP` 原新闻区域点击记录会展开归档字段、核验状态与匹配货币对的公开日频历史图；`TOP FX` 原要闻区按主题选择各自关联公开观察 | 归档未包含可核验新闻原文或实时新闻源；不补写全文，不宣称实时新闻，不从数据图推断新闻因果 |
| BICO 在原区内升级 | `BICO` 原“行业货币关联”选择器和关联卡保留；行业与货币对选择驱动对应公开日频数据状态、详情及历史图 | 行业关联是资料观察，不表示因果、预测或交易建议；日频数据非实时／非可执行 |
| 其余功能不再加载无关内容 | 删除非专属入口后一律追加 `ForexResearchLayer` 的做法，并移除顶部提示及“定位当前功能区数据扩展”操作；正在逐项解除终端映射中原面板后的重复附加工作区 | 原有冻结面板、菜单层级与入口仍保留，数据不可用时显示真实加载／空／错误状态；不将尚未迁入原组件的项目误报为完成 |

## 公开日频图的恢复过程

TOP FX 与 BICO 初次截图显示空图，原因是先前 5 分钟缓存保存了查询失败的日频结果。对既有 `getPublicReferenceRates({ refresh: true })` 接口强制刷新后，端点返回了例如 `EUR/USD` 的 2026-08-27 实际公开观察和历史数组；随后 BICO 原区截图可见日期与曲线。调用继续使用已有 Frankfurter 日频参考适配层，其定义的缓存、非实时和非可执行边界未改变。

## 验收结果

菜单静态映射测试现验证 **25** 个可点击外汇代码入口，包含已恢复的 FIRS 且不包含 GP。最新原区新闻、TOP FX 主题、BICO 行业选择、FXIP 详情、FXDS 既有交互及 WCRS 货币排行的定向回归共 **3 个文件、20 个用例**通过；完整 TypeScript 检查通过。生产构建与全量移动／桌面复核仍在后续范围内，不能以此前结果替代当前收敛后的验收。
