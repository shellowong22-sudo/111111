# 外汇原功能区迁回进度

本记录用于纠正此前“原面板后追加独立工作区”的实现方向。当前整改以终端映射为边界：仅当原组件内已经拥有适用的字段、计算、详情、图表和状态时，才解除后续重复挂载；历史工作区源文件保留但不作为当前终端默认内容。

| 已解除终端重复挂载 | 原组件内保留的可用能力 | 数据／执行边界 |
|---|---|---|
| WCR、WVOL、XCCY、GMM | 原有地区、矩阵、基差和宏观驱动器视图 | 动态路径仅在适用处标示为模拟；不称实时市场数据 |
| FXDS、FXTF | 公开日频检索、代码字段、详情、刷新和本地 CSV | Frankfurter 公开中央银行日频参考；非逐秒、非可执行 |
| FRD、FXFA | 用户输入远期曲线、CIP 计算、期限／远期偏移敏感度和本地 CSV | 计算输出不是市场报价、套利执行或交易建议 |
| BFIX、STNI | BFIX 授权不可用与公开日频对照；会话内订阅规则状态 | 不以归档字段替代许可定盘；不发送邮件或外部通知 |
| OVML | 原始 Garman-Kohlhagen 输入、定价、微笑、策略、Greeks 和图表 | 默认参数与衍生可视化标为模型示例，非实时期权报价 |

当前终端映射中已经没有“原面板后追加重复工作区”的复合挂载。MYQ、TOP FX、BICO 与 MARS FX 是当前源码检索未发现独立归档原面板的唯一承载组件，仍需按其归档来源与功能完整性分别复核；此记录不宣称全部 25 个可见外汇入口均已完成迁回。
