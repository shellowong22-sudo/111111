# 管理后台 AI 数据采集设计与验收记录

## 入口与权限

新增受既有管理员路由保护的 `/admin/data-ingestion`，并在 `AdminLayout` 左侧导航中添加 **AI 数据采集**。该入口集中管理新闻 RSS、投资标的公共日频读取、计划控制和运行审计；普通用户不能绕过既有 `ProtectedRoute` 或 `adminProcedure` 访问。

## 数据任务边界

| 任务 | 实际来源／保存内容 | 自动化状态 | 明确不做的事 |
| --- | --- | --- | --- |
| 新闻采集 | 许可 RSS／API 的标题、链接、发布时间与有限摘要；AI 待审核通俗解读 | 单一来源可按 10／30／60 分钟计划执行 | 不抓取或保存来源全文；不自动发布；不隐藏来源。 |
| 投资标的采集 | Yahoo 公共日频 OHLCV 的最近实际观测、币种、来源与失败原因 | 单一目标可按 10／30／60 分钟检查 | 不产生分钟 K 线、盘口、期权链、Bid／Ask 或订单。 |
| NCEO 期权报价 | 仅显示授权状态卡 | 等待授权数据提供方 | 不以爬虫、模型链或静态数字充当实时买卖价。 |

每个计划回调均要求 cron 身份，并以平台认证的 `taskUid` 反查单一来源或标的；请求体中的标识不用于决定任务对象。已删除业务行的孤儿计划返回 2xx 跳过，避免平台无意义重试。计划创建仅允许生产部署的管理员操作，开发预览不自动创建后台任务。

## 网站配置、批处理与频率扩展（2026-08-27）

新闻来源表单现只要求**网站名称**与**网站网址**。服务端仅对无凭据的公开 HTTPS 地址发起手动重定向模式的请求：若网址本身是 RSS／Atom XML 则直接使用；若为主页则只识别标准 `<link rel="alternate" type="application/rss+xml|application/atom+xml">` 订阅声明。系统不解析、保存或转载普通网页正文；发现失败以 `SOURCE_PUBLIC_FEED_NOT_DISCOVERED` 返回且不会保存假来源。

来源可以选择每批 10、25 或最多 50 条元数据，以及“稳定队列”或“全量即时”草稿模式。两种模式都只保存标题、链接、时间与有限摘要并维持去重，均不自动审核或发布。稳定队列单轮最多生成 10 条草稿；全量即时模式最多尝试当前 50 条，并以四并发小批运行，在接近 HTTP cron 两分钟上限前停止，未开始条目继续保留 `queued`。界面和审计会显示新增、已处理、草稿、失败与待处理计数。

新闻与公共日频目标计划均可选择 10 分钟、30 分钟、1 小时、6 小时、12 小时、24 小时的六字段 UTC cron。10 分钟仅代表检查间隔，不承诺来源实时更新。当前未创建任何新计划：仍须先保存检查点、由用户发布生产环境，之后才允许管理员在界面启用。

行情 API 接入配置已收敛为三个必填项：提供方名称、无凭据 HTTPS API 地址和密钥环境变量名。提供方代码、市场覆盖、延迟等级与字段能力为选填高级项，留空使用明确默认值。密钥不保存到数据库、前端或日志；仅检查同名安全环境变量是否存在，并如实显示“等待密钥”或“等待字段适配”。实际行情读取和 NCEO 真正 Bid／Ask 仍需授权数据商及字段适配。

本批验证：新闻服务单元测试 6/6、管理员入口与表单测试 3/3、股票驾驶舱联动测试 1/1 均通过；`tsc --noEmit` 通过；8GB 内存 Vite 生产构建与服务端打包通过。`/admin/data-ingestion` 和 `/terminal?module=stocks&open=cockpit` 已分别在桌面及 390×844 窄屏抽样。截图中的公开 Data API 配额耗尽提示为来源配额状态，驾驶舱保持真实加载／不可用边界，未以模拟价格替代。

## 新浪财经同步与 RSS 选填修复（2026-08-27）

用户以 `https://finance.sina.com.cn/` 创建来源时收到 `SOURCE_PUBLIC_FEED_NOT_DISCOVERED`。被动核验显示，该主页没有公开 RSS／Atom alternate 声明；系统现在仅将该精确主页映射至已核验的公开新浪财经 RSS，而不读取主页或新闻正文。管理员还可在两处来源表单选填 RSS／Atom 地址：填写时优先经 HTTPS、无凭据、非本地地址校验后使用，留空时才尝试标准声明发现或这一条受限映射。

新浪财经公开 RSS 目录当前列出九个频道，但本次逐个只读探针均返回 2018-09-23 的 0 条 XML 频道。因此“立即同步”返回“同步已完成：该公开订阅本次未提供可导入条目”才是正确状态，不能改报启动成功、虚构草稿或退回正文抓取。按钮已实际调用服务端同步并完成来源读取、去重与审计；只有来源返回新条目时才会生成待审核 AI 草稿。

开发预览中的新闻与日频计划按钮改为“发布后启用计划”，对应行显示“待发布后启用”。当前环境不会创建无效后台任务；用户在成功发布生产版本后点击该按钮，系统才会实际创建单一来源／单一标的的认证计划任务。RSS／Atom 选填、空订阅提示、新闻同步及计划状态已通过新闻服务和管理员入口 10 个定向用例、`tsc --noEmit`、桌面和 390×844 窄屏抽样验证。
