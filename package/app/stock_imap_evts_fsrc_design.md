# IMAP、EVTS 与 FSRC 账户级增强设计

**范围：**所有能力仅追加于股市原面板之后；不改写 23 项原菜单、面板、字段、顺序或窗口标识。

| 入口 | 追加能力 | 真实数据与账户边界 | 不可用时的处理 |
| --- | --- | --- | --- |
| IMAP | 日频收盘与同日成交量联动 | 服务器读取同一公开图表响应中的日频 `close` 与 `volume`；图表将日期对齐后分别呈现价格线与成交量柱。 | 任一历史序列不可读时，不拼接缓存样本或替代成交量；明确显示该序列不可用。 |
| EVTS | SEC 表单类别筛选与偏好 | 表单、日期、文件名和类别继续直接读取 SEC 申报目录；当前账户仅保存已选择的类别，不保存 SEC 文件正文。 | 未登录可临时筛选；登录前后均不以示例申报替代 SEC 结果。 |
| FSRC | 账户级观察清单与覆盖变化提醒 | 当前账户保存最多十个代码和上次已确认的可读性快照；检查时以新读取的状态、历史点数、最近观测日期与快照对比。 | 不可读代码仍写为真实不可读状态；只有可读性新增/消失或历史覆盖缩短才触发醒目变化提醒。 |

> **账户隔离：**EVTS 偏好和 FSRC 清单均按用户标识唯一保存。公开市场观察与 SEC 目录不写入账户数据库；数据库只保存用户主动选择的筛选、代码和轻量覆盖快照。

> **终端内边界：**新增界面不添加外部跳转、自动交易、估值、预测、排名或模拟值。核心数据、图表、筛选、状态与反馈均直接在终端窗口内显示。

## 实现与验证记录

| 核验项 | 结果 |
| --- | --- |
| 数据完整性 | 公开个券读取已返回与收盘价格同日对齐的真实 `volume` 字段；IMAP 只在收盘和成交量均实际返回的日期绘制联动图。 |
| 账户隔离 | 迁移 `0036_closed_tomas.sql` 已应用并核验：EVTS 偏好按 `user_id + preference_key` 唯一保存，FSRC 清单按 `user_id` 唯一保存。 |
| 偏好和清单反馈 | EVTS 显示保存成功、读取失败和未登录边界；FSRC 支持保存、恢复、重新检查，并仅对可读性变化或历史点数缩短显示醒目提醒。 |
| 原内容保护 | 原股市菜单及 23 项保留窗口未修改；新增能力只通过研究层路由接入 IMAP、EVTS 和 FSRC。 |
| 回归 | 前端与服务端低内存打包成功；原内容保护、差异化、SEC 摘要和全量测试通过：73 个测试文件、394 项测试。 |
