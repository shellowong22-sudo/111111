# 地方债发行人证据归档与授权成交设计

## 不可变边界

SMUN 的原发行人筛选、档案、图表、标签和交互不修改。发行人证据工作区由 `MunicipalResearchLayer` 仅在 `SMUN` 的原面板之后追加；交易数据显示区由同一层仅在 `MSRB`、`MBWD` 和 `DEAL` 的原面板之后追加。没有可读的授权字段时显示状态、缺失原因和重新读取操作，不显示虚构成交、价格、收益率、CUSIP、库存或经纪商评分。

## MSRB/EMMA 成交数据契约

MSRB 官方订阅材料确认实时成交与定期报告可按订阅提供，但当前会话不存在 MSRB/EMMA 连接器，也没有可安全假设的通用认证端点。因此成交适配器在取得实际订阅连接参数前只能处于 **未配置** 状态。配置后只接受实际返回的字段，并标准化为：交易时间、CUSIP、发行人、证券描述、成交价格、收益率、面额、成交方向、延迟、来源与读取时间。每一字段均保留可空性；未知字段不推断、不补全。

## 发行人证据归档模型

| 对象 | 主要内容 | 数据治理 |
| --- | --- | --- |
| 证据包 | 名称、发行人、状态、所有者、当前版本、审批截止 | 账户级访问；不保存完整第三方文件字节。 |
| 证据文件 | 官方链接、标题、来源机构、文件日期、内容指纹、可核验摘录、获取时间 | 同一所有者按指纹去重；只保存链接、元数据与人工证据片段。 |
| 团队权限 | viewer、editor、reviewer | 所有者可授权或撤销；审阅者不能修改包或文件。 |
| 版本快照 | 每次提交时冻结文件标识、指纹、来源链接与核验状态 | 用于提交后比较；不复制外部文件原文。 |
| 审阅决定 | approved 或 changes_requested，带说明和时间戳 | 只有 reviewer 可处理；所有审阅者批准后才转为 approved。 |
| 追加式审计 | 创建、更新、共享、撤销、提交、审阅、状态变化 | 记录操作者、目标成员、说明和时间。 |

## 状态与交互

`draft` 可编辑；`submitted` 锁定文件清单并等待审阅；任一审阅者要求调整即转为 `changes_requested`；编辑后回到 `draft`；所有指定审阅者批准后转为 `approved`。提交前至少需要一名审阅者与一份已归档的官方证据。提交时所有审阅者收到终端内通知；审阅结果写入全局通知中心并通过既有实时推送机制呈现。
