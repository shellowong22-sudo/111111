# EIA 能源资料与商品观察组合设计

| 能力 | 数据或账户边界 | 终端内实现 |
| --- | --- | --- |
| 原油商业库存 | EIA 官方 `WCESTUS1w.xls` 的周度美国商业原油库存（不含战略石油储备），单位为千桶。 | 服务端只读下载并解析 `Data 1` 工作表；展示实际周度折线、最近观察、相邻周变化与来源时点。 |
| 炼厂利用率 | EIA 官方 `WPULEUS3w.xls` 的周度美国炼厂可操作产能利用率，单位为百分比。 | 服务端只读下载并解析同名官方 XLS；与库存共用日期对齐图，但不把不同观测日补造为共同周。 |
| 公开数据许可边界 | EIA API 目录在无 API key 时返回 `API_KEY_MISSING`；本期不请求、存储或伪造密钥。官方公开历史 XLS 无需密钥且可实际读取。 | 明示为 EIA 周度公开资料，不标示为实时库存、日内数据、交易信号或原油供需预测。 |
| 账户级观察组合 | 仅保存用户主动选取的公开序列、可选阈值与上次检查快照；按 `user_id` 隔离。 | 登录用户可创建、编辑、保存和恢复组合；未登录只允许临时研究，不保存账户数据。 |
| 变动提醒 | 只在新实际观察超过用户保存的绝对变化阈值时生成去重账户提醒；提醒存储来源日期和前后观察值。 | 组合手动刷新时即时评估并写入通知记录；不伪称交易所实时推送，也不在后台无界限轮询。 |

> **EIA 读取实测。** 原油库存官方文件最新观察为 2026-08-14，发布日为 2026-08-19；炼厂利用率文件同样提供周度 `Data 1` 工作表。数值日期为 Excel 日期序列，服务端转换为 ISO 日期后才供终端绘图。

## 参考来源

[2]: https://www.eia.gov/dnav/pet/hist_xls/WCESTUS1w.xls "EIA Weekly U.S. Ending Stocks excluding SPR of Crude Oil"

## 实现与验证记录

| 核验项 | 结果 |
| --- | --- |
| EIA 数据真实性 | 终端接口实测返回 2026-08-14 的商业原油库存 **428,815 千桶**和炼厂利用率 **97.2%**；解析器已排除 XLS 尾部空行，不会把空值写成零。 |
| 终端内图表 | FDM 原面板之后追加库存柱图和利用率折线图，支持 1 年、3 年、5 年及全历史窗口，并显示来源、频率、单位、观测日期和真实空状态。 |
| 账户隔离 | 迁移 `0037_sloppy_sister_grimm.sql` 已应用并核验。观察组合按 `user_id + name` 唯一保存；无登录访问账户接口返回 HTTP 401。 |
| 提醒时效 | 当前已部署的小时级通知回调会读取活跃组合并按稳定键去重，将符合阈值的新实际观察写入通知中心及实时推送通道。首次检查只建立快照，不生成伪提醒。 |
| 保护与回归 | 原菜单和九个原面板仍由 SHA-256 测试锁定；专项测试及全量回归通过：75 个测试文件、400 项测试。 |
