# 优先股终端内数据源矩阵

**参考时点：2026-08-20（UTC）**  
**终端原则：原始数据、筛选结果、条款摘录、比较图表和研究计算均在本终端呈现；原始来源仅用于后台读取与可悬停溯源，不提供跳转式核心阅读路径。**

| 能力类别 | 终端内数据依据 | 可直接呈现字段 | 使用边界 | 状态 |
| --- | --- | --- | --- | --- |
| 发行主体与申报目录 | SEC EDGAR `data.sec.gov/submissions` | 主体名称、CIK、证券代码、申报表单、申报日期、文件编号、主文件名 | 仅代表 SEC 收录的申报元数据；不代表逐笔报价、成交或完整优先股全市场目录 | 已实测可读 |
| 条款与事件证据 | SEC EDGAR 申报 HTML/TXT 与已列示附件 | 优先股相关表单索引、申报日期、表单类型、终端内文本片段与关键词命中 | 非结构化字段只展示可直接提取的原文片段；无法确认的条款保持空状态 | 可读取，需逐文件解析 |
| 发行主体报表事实 | SEC EDGAR Company Facts | 标准 XBRL 报告期、单位、已申报财务概念 | 仅使用标准概念；发行条款常见于自定义标签或非结构化文件，不以 Company Facts 替代条款 | 已验证官方能力 |
| 无风险利率参照 | FRED 公共 CSV（DGS2/DGS5/DGS10/DGS30） | 最近观察值、历史曲线、日度变化、观察日期 | 公开历史观察，不是可执行国债报价、个券收益率或优先股估值结论 | 已实测可读 |
| 官方期限利率交叉核验 | 美国财政部 Daily Treasury Par Yield Curve XML | 日度期限、官方收益率曲线、观察日期 | 仅作期限风险与利率敏感性参照；不作为优先股个券报价或收益率 | 已验证公开接口 |
| 信用环境参照 | FRED / ICE BofA 指数级 OAS（IG、AAA、AA、BBB、HY） | 最新 OAS、历史序列、观察日期、变化 | 仅为公司债指数级信用环境参照，不等同于单只优先股利差、评级或违约概率 | 项目既有读取路径已验证 |
| 个券价格、收益率、成交与盘口 | 需授权的交易所、场外交易或经许可聚合数据 | 无 | 未接入可再分发的免费结构化个券报价源；不生成代理价格、虚构成交或替代流动性指标 | 真实空状态 |
| FINRA TRACE 个券成交 | 需具备适当访问权限的 FINRA 数据服务 | 无 | 未确认当前账户具备适用于优先证券逐笔成交的权限；不显示替代成交数据 | 真实空状态 |
| 指数成分、优先股 ETF 持仓与授权指数 | 授权指数或基金披露文件 | 仅在可核验的公开申报中提取明确字段 | 不将滞后披露误读为实时持仓或指数实时构成 | 受披露范围约束 |

## 关键事实边界

SEC 官方说明确认，`data.sec.gov` 的公司申报记录与 XBRL 数据以 JSON 提供，且不要求认证密钥；提交记录与 XBRL 结构会随披露更新。SEC 同时指出其数据服务不支持浏览器跨域脚本访问，因此将由本终端服务器读取并在本站展示，而不让用户跳转或在浏览器直接请求。[1]

FRED 的公开文档说明其检索接口用于匹配经济数据序列。项目将复用已核验的公开 CSV 读取方式作为利率和信用环境的历史参照，并明确区分“公开历史观察”与“个券可执行报价”。[2]

美国财政部的日度利率数据服务支持以 GET 请求读取 XML 格式的国债票面收益率曲线，并提供按年、按月和分页访问方式；该资料将用于与 FRED 曲线交叉核验和期限敏感性研究，而不会被误标为优先股实时报价。[3]
