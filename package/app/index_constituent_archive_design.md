# 指数成分变更归档与篮子协作设计

## 公开成分变更归档

归档只读取纳斯达克投资者关系页面的 Nasdaq-100 官方公开公告。当前已核验的来源目录包括：[2026 年 6 月季度调整公告](https://ir.nasdaq.com/news-releases/news-release-details/nasdaq-100-indexr-june-2026-quarterly-changes) 与 [2025 年年度重组公告](https://ir.nasdaq.com/news-releases/news-release-details/annual-changes-nasdaq-100-indexr-2)。服务端只归档源页面实际返回的公告标题、公告日期、生效日期（如页面可解析）、新增/移除数量、代码及来源读取时间；无法解析的字段保持空值。

归档不会把新闻转载、估计名单、指数成分快照、历史回填或未授权指数提供商数据补为事件。S&P、MSCI 等指数的免费机器可读成分变更资料当前不进入该归档；它们在终端中显示公开资料边界，而不是样例时间轴。

## 权重影响提示的资料边界

已核验 Nasdaq 的[指数概览](https://indexes.nasdaqomx.com/Index/Overview/NDX)、[全球指数政策](https://www.nasdaq.com/products/global-indexes/policies)和 [Nasdaq-100 公司目录](https://www.nasdaq.com/products/global-indexes/nasdaq-100/companies)。政策页说明选定指数的成分及权重会在再平衡后发布；但当前可免费直接读取的页面没有提供与每次历史事件生效日对应的可机器读取成分权重表。公司目录只提供成分列表且页面标注的更新时间早于当前归档事件。

因此，事件悬停提示将显示“整体权重影响：未披露/不可核验”，并说明公告只确认新增与移除名单，未提供该事件生效日的成分权重或整体权重变动。终端不会用当前权重、ETF 持仓、第三方网页权重或等权假设回填历史影响；当未来官方公告同时提供可核验的事件日权重表时，才允许显示实际权重变化值和来源日期。

## 自设指数篮子协作

账户级篮子只保存用户主动输入的名称、描述、来源窗口与成分代码/名称/权重。成分总权重必须为 100%，代码不得重复，每个账户只能查看自有篮子或获得明确共享授权的篮子。

| 权限 | 查看 | 编辑篮子 | 管理共享 | 撤销共享 |
| --- | --- | --- | --- | --- |
| 所有者 | 是 | 是 | 是 | 是 |
| 编辑者 | 是 | 是 | 否 | 否 |
| 只读者 | 是 | 否 | 否 | 否 |

每次创建、更新、共享与撤销共享都会写入账户级审计记录。成员目录仅在登录后查询最少必要的成员名称、账户编号和角色信息；所有权、共享对象存在性及写入权限均由服务端复核。
