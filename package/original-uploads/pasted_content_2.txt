# 项目完整改造指令：后台自动化管理、内容生成与前端数据推送

请完整阅读并严格执行以下要求。所有条款都是必须完成项，不得遗漏、删减、合并、曲解或用演示页面代替。请直接完成开发、联调、自测、修复和验收，不要中途反复向我确认一般性问题，也不要交付半成品。

## 一、最高优先级：前端零改动

本项目的前端页面、前端代码、组件、路由、样式、文案、交互、现有功能、现有接口地址、接口字段和前端逻辑全部保持不变。

严禁修改前端任何内容，严禁为了实现后台功能而新增、删除、重写或调整前端功能。前端只能按照原有代码、原有接口和原有数据结构读取后台已发布的数据。

这里的“前端可以查看后台推送的数据”是指：后台把符合前端现有接口格式的数据，写入或推送到前端原本读取的数据接口、数据表或数据源；前端通过原有方式读取并展示。不得把后台管理配置、后台数据库结构、内部任务日志、管理员权限、爬虫配置、AI 配置等内部管理内容直接暴露给前端。

## 二、后台模块管理必须真实可用

当前模块管理存在大量死按键、空状态和无实际作用的内容。请全面修复，不允许只做 UI 展示。

请完整盘点前端现有的所有功能模块、页面数据、栏目、新闻列表、榜单、推荐位、搜索内容、详情内容、公告、下载、数据卡片和其他前端数据入口，并在后台全部建立模块记录。

每个后台模块必须有明确对应关系：

> 后台模块名称 → 前端现有功能 → 前端现有页面/位置 → 前端现有接口或数据表 → 可推送的数据类型 → 推送后的前端展示结果。

每个模块必须支持以下操作，并且每个按钮都必须真实生效：

- 启动该模块的数据生成；
- 停止该模块的数据生成；
- 启动该模块的数据推送；
- 停止该模块的数据推送；
- 单个模块立即执行；
- 批量选择多个模块执行；
- 全部模块一键执行；
- 查看待推送数据；
- 查看已推送数据；
- 查看推送失败数据；
- 失败重试；
- 查看推送时间、数量、目标接口和结果；
- 撤回本次推送；
- 回滚到上一个数据版本。

所有操作必须有真实的后端逻辑、持久化状态、执行记录和日志，不得只弹出“操作成功”。

## 三、图三：修复日志推送与前端无法查看的问题

图三显示后台已经记录新闻推送日志，但这些新闻并没有真正进入前端，前端无法查看后台所谓的“已推送内容”。请重点修复这一问题。

后台每次推送必须真实完成以下流程：

1. 生成或采集新闻、数据或图文内容；
2. 保存完整内容，包括标题、正文、摘要、作者、来源、发布时间、分类、标签、图片、数据表、可视化数据和唯一 ID；
3. 进入后台审核或发布队列；
4. 审核通过后按照前端现有字段格式进行发布；
5. 写入前端当前实际读取的数据接口、数据表、数据集合或数据源；
6. 前端通过原有接口和原有逻辑读取到这条内容；
7. 后台记录完整推送结果；
8. 后台能够查看前端是否成功读取或展示该数据。

“已推送”不能只代表后台生成成功或写了一条日志，必须代表数据已经写入前端现有读取位置，并且能够通过前端原有功能查看到。

请增加后台推送详情页，至少展示：新闻标题、完整正文、摘要、图片、来源、分类、标签、数据表、可视化配置、生成时间、审核状态、发布时间、推送时间、目标前端模块、目标接口/数据表、推送条数、数据版本、推送状态、失败原因和前端读取验证结果。

## 四、图四：自动化模块必须支持全部前端模块

自动化模块不能只启动少数模块，也不能只显示一个“执行自动化”的空按钮。自动化必须覆盖前端所有现有数据模块。

自动化执行范围必须包括：

- 单个前端模块；
- 多个选中模块；
- 某一类模块；
- 某一组模块；
- 全部前端模块。

每个模块旁边必须有独立的“启动数据生成”“启动数据推送”“查看任务”“查看结果”操作。必须支持批量执行，也必须支持只针对某一项前端功能执行。

一键启动“全部自动化”后，必须实际执行：

> 读取所有模块配置 → AI 爬虫采集或生成数据 → 清洗数据 → 去重 → 分类 → 生成新闻/摘要/图文 → 生成数据表或可视化数据 → 进入审核 → 发布 → 推送到对应前端现有接口或数据表 → 验证前端可读取 → 保存完整日志。

## 六、每个模块必须推送完整内容

不能只给前端推送标题或几条摘要。根据模块类型，必须推送前端原有数据结构能够接受的完整内容。

新闻类内容至少包括标题、正文、摘要、作者、来源、来源链接、发布时间、更新时间、分类、标签、封面图、内容 ID 和发布状态。

推送前必须进行字段校验，保证不会因为字段缺失、格式错误或类型错误导致前端无法显示。

禁止所有模块使用同一批新闻、相同标题、相同正文、相同图片、相同数据表或相同排序。必须进行标题去重、正文去重、图片去重、主题去重和跨模块重复检查。

后台每次任务必须统计：新增内容、更新内容、重复内容、跳过内容、失败内容、审核内容、已发布内容和已推送内容。
