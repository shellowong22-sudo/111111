鑊仔食譜（獨立版）使用說明
==========================

呢個資料夾係一個唔使 Claude 都用得嘅網頁 App。
食譜、購物清單、餐單、搭配推薦、圖表、計時器、轉盤、雪櫃管理全部照用；
AI 功能（生成食譜、影相認食材、問鑊仔）就要喺 Claude 入面先用到。


一、放上網（大約 2 分鐘，免費）
------------------------------
1. 用電腦開 https://app.netlify.com/drop
2. 將成個「wokzai」資料夾拖入去（或者拖個 zip 檔）。
3. 註冊／登入 Netlify 保留網站（唔登入，網站一個鐘後會冇咗）。
4. 你會得到一條網址，例如 https://xxxx.netlify.app

手機用法：用瀏覽器開條網址 →
  iPhone：Safari 撳「分享」→「加入主畫面」
  Android：Chrome 撳右上「⋮」→「加到主畫面」／「安裝應用程式」
之後就好似一個 App 咁，冇網都開到。

※ 直接喺手機開 index.html 檔未必行到，一定要放上網開網址。


二、全家即時同步（Firebase 免費，大約 10 分鐘，只需一個人做一次）
------------------------------------------------------------
Firebase 免費 Spark 方案每日有 5 萬次讀取、2 萬次寫入，一家人用綽綽有餘，唔使信用卡。

1. 用 Google 帳戶開 https://console.firebase.google.com
   撳「建立專案／Create a project」，改個名（例如 wokzai-family），Analytics 可以唔開。
2. 喺專案主頁撳網頁圖示「</>」加一個 Web App，改個名，撳註冊。
   會見到一段 firebaseConfig = { apiKey: "...", projectId: "...", ... }，成段複製。
3. 左邊揀「Firestore Database」→「建立資料庫／Create database」，
   地點可以揀 asia-east2（香港），揀正式版模式（production mode）。
4. 去「規則／Rules」分頁，將入面嘅內容全部換成下面呢段，撳「發布／Publish」：

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /families/{fam}/items/{item} {
      allow read, write: if fam.size() >= 20;
    }
  }
}

5. 打開你個鑊仔食譜網址 → 撳右上角狀態掣（或者主頁「想同屋企人同步？」）→
   貼上 firebaseConfig → 撳「建立家庭」。你部機原本嘅資料會自動上載。
6. 撳「邀請屋企人」：俾屋企人掃 QR code，或者用 WhatsApp 傳邀請連結。
   佢哋撳連結 →「加入」，就會即時同步。

   iPhone 注意：加咗去主畫面嘅 App 同 Safari 嘅資料係分開嘅。
   iPhone 屋企人請先「加入主畫面」，再喺主畫面個 App 入面
   「家庭共用」→ 貼上邀請碼 →「加入家庭」。

安全提示：邀請碼／連結好似屋企鎖匙，只傳俾屋企人。
有邀請碼嘅人可以睇同改你屋企嘅清單同餐單。


三、唔想設定任何嘢？用「分享碼」
------------------------------
家庭共用 →「複製分享碼」→ WhatsApp 傳俾屋企人 →
佢喺「貼上屋企人傳嚟嘅分享碼」貼上 →「合併」。
清單、餐單、雪櫃同食譜會合併埋一齊（唔會刪走對方嘅嘢；剔咗買咗會跟住更新）。


四、備份
--------
家庭共用 →「下載完整備份檔」（包括相片）。換手機或者清咗瀏覽器資料，
用「匯入備份檔」就搵返晒。
